Syllabus
Design and implement computer programs involving branching, iteration and functions in an OOP language for an identified need or opportunity

  Learning Intention and Success Criteria

Learning Intention - Students will:

  • Design and implement software solutions using branching, iteration, and functions within an OOP framework to address specific needs or opportunities.

Success Criteria - Students can:

  • Demonstrate the use of branching (if-else, switch-case statements), iteration (loops like for, while), and functions in creating software.
  • Develop a small project or a component of a larger project that utilizes OOP concepts to solve a real-world problem, documenting the process and the code effectively.

  Content

Together, branching, iteration, and functions (methods) enable developers to create more modular, reusable, and maintainable code in object-oriented systems. They help manage complexity by dividing tasks into smaller, manageable parts and defining clear interfaces for objects.

 

These are all concepts that you have learnt already, to summarise:

  • Branching involves making decisions within the program. It uses conditions to determine which blocks of code to execute. For example, if, else, and elif statements allow the program to execute different code based on different inputs or states. In OOP, branching can be used within methods to determine how an object should behave under different conditions. Refer to 1.5 Structured algorithms for more information.
  • Iteration refers to looping through data structures or repeating some action until a condition changes. Common iterators include for loops and while loops. In OOP, iteration might be used to perform actions on each item in a collection of objects, such as invoking a method on every object in a list. Refer to 1.5 Structured algorithms for more information.
  • Functions are blocks of code that perform specific tasks and can be called as needed. In OOP, these are often implemented as methods, which are functions that are associated with a specific class. Methods define behaviours for class instances and can access and modify the state of these instances. Refer to 1.8 Procedures and functions for more information.
