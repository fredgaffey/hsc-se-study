## [`calculator/`](calculator): the King's Maths calculator (assessment)

A Python calculator built in three stages, with documentation.

| | |
|---|---|
| [Calculator documentation.docx](calculator/Calculator%20documentation.docx) | Final documentation |
| `p1/`, `p2/`, `p3/` | Each stage: `main.py` (code), `final.txt` (pseudocode/notes) and a screenshot. `p3/` also has the **level 0 and level 1 DFDs** and the **structure chart** |

## [`oop-game-at2/`](oop-game-at2): Dungeon Game (AT2, object-oriented programming)

A 2D dungeon game in Python and Pygame: character classes (Knight, Wizard and more), enemies, traps, items, levels and tests. A good example of classes, inheritance and splitting a program into modules.

| | |
|---|---|
| `code/` | The game. See `code/README.md` to install and run (`pip install -r requirements.txt`, then `python main.py`) |
| `documentation/` | Documentation, class diagram, DFDs (level 0 and 1), Gantt chart, and the **walkthrough video** (4:48) |
| `archive/` | Video plan notes, git structure diagram, an earlier DFD |

The character sprites in `code/assets/` are third-party art packs used for the assessment. If you reuse them, check their original licences.
