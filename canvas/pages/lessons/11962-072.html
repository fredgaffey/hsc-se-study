Syllabus
Design, develop and implement a user interface (UI) to control a mechatronic system

  Learning Intention and Success Criteria

Learning Intention - Students will:

  • be able to design, develop, and implement a user interface (UI) to control a mechatronic system.

Success Criteria - Students can:

  • design a user interface that is intuitive and user-friendly for controlling a mechatronic system.
  • develop the UI using appropriate software tools and programming languages.
  • implement the UI to effectively control various functions and components of the mechatronic system.

  Content

The integration of User Interface (UI) in robotics marks a significant advancement in the way humans interact with machines. A well-designed UI is pivotal in enhancing the functionality, efficiency, and safety of robots, making them more accessible and effective for a variety of applications. This essay delves into the myriad ways UI is utilised in robotics, highlighting its critical importance.

 

Control Interfaces

One of the fundamental applications of UI in robotics is in control interfaces. These interfaces allow users to directly manipulate and control robotic systems.

  • Manual control interfaces, such as joysticks and touch screens, enable operators to guide robots in performing precise tasks. For instance, in manufacturing, robots are often manually controlled to assemble intricate components.
  • Teleoperation interfaces extend this capability to remote locations. Such systems are indispensable in environments where direct human intervention is risky or impossible, such as space exploration, underwater missions, or disaster response scenarios.

 

Monitoring and Feedback

Effective monitoring and real-time feedback are crucial for the efficient operation of robots.

  • Dashboard displays are essential UI components that provide real-time data on robot status, performance metrics, and diagnostics. These dashboards enable operators to monitor multiple robots simultaneously, ensuring they operate within optimal parameters.
  • Visual feedback through integrated cameras and sensors further enhances situational awareness, allowing operators to make informed decisions based on real-time imagery and sensor data. This is particularly vital in precision tasks such as robotic surgery or detailed assembly processes.

User Experience (UX)

The success of robotic systems heavily relies on the user experience (UX) offered by their UIs.

  • Intuitive design is paramount, ensuring that interfaces are user-friendly and reduce the learning curve for new users. For instance, in healthcare, robots assist in patient care, and the UI must be straightforward enough for medical staff to use without extensive training.
  • Haptic feedback adds another layer of interaction, providing tactile sensations that enhance control, especially in teleoperation scenarios. This feedback can simulate the sense of touch, allowing operators to feel the environment the robot is interacting with, thus improving precision and control.

Safety and Compliance

Ensuring safety is a critical aspect of robotics, and UIs play a crucial role in this domain.

  • Emergency stop and safety protocols are integrated into UIs to provide quick and reliable methods to halt robot operations in case of emergencies. This is essential in environments where humans and robots work in close proximity, such as in collaborative robotics in manufacturing.
  • Compliance and monitoring interfaces ensure that robots operate within predefined safety parameters, adhering to industry standards and regulations. These interfaces help in monitoring robot behaviour and implementing corrective measures when deviations occur.

 

Case Study: NASA

In all systems that involve interactions between humans and machines, the element that defines the quality of that interaction is the human/machine interface, also known as the user interface. A graphical user interface (GUI) can make the human interaction more engaging and intuitive, constrain user inputs to valid ranges and units, supply tabular and plot-based output where needed, and provide users with data from sensors on the robots that are needed for control.

JPL Robotics has created a number of very successful user interfaces tailored to the robotic systems being controlled. These robots have ranged from multi-arm manipulators for microgravity deployment or terrestrial surgical applications, to legged prototype-rovers for rough terrains, to multi-wheeled rovers including flight systems such as the Mars Pathfinder Sojourner Rover, the Mars Exploration Rovers (MER), Spirit and Opportunity, the Phoenix Lander, the Mars Science Laboratory (MSL) rover Curiosity, and the current Mars 2020 (M2020) rover and Helicopter, Perseverance and Ingenuity.

 

Key Interfaces Developed at JPL:

  1. RSVP (Robot Sequencing and Visualisation Program)

    • Used for all surface operations in Mars missions since 1997.
    • Creates all command sequences for robotic operations sent to Mars rovers and landers.
    • Tools within RSVP:
      • RoSE (Rover Sequence Editor): Supports all commands in the mission-command dictionary and interfaces with simulation tools.
      • HyperDrive: Provides multiple 3D graphics interfaces to stereo images and 3D terrain-model data for planning rover motions.
      • ArmSketch: Visual sequencing tool for generating arm sequences with optimised path and collision avoidance.
      • MobSketch: Visual sequencing tool for generating drive sequences.
      • ROCS (Robotic Operations and Computational Services): Provides stateless, RESTful API for rover simulation, planning, and operations.

  2. SSim (Surface Simulation)

    • Flight-software-in-the-loop simulation software predicting rover command outcomes before uplink to Mars.
    • Supports quick iteration of command development by rover planners.
    • Takes inputs like rover command sequences, terrain models, and rover memory state to output motion history and command durations.
    • Used in both MSL and M2020 for sequence validation and verification.

  3. Honeycomb 3D Visualisation Platform

    • General, web-based 3D visualisation platform for understanding robotic systems from development to operations.
    • Used in Mars 2020 for visualising autonomy products from the enhanced driving navigation system.
    • Displays flight products during autonomous driving to help operators understand and debug the process.
    • Allows toggling of displays, timeline scrubbing, and interaction with 3D views to analyze rover decisions.
    • Planned for expansion to other missions.

 

Applications and Impact:

  • RSVP: Critical for planning and executing complex rover missions, enabling precise control and movement on Mars.
  • SSim: Enhances mission success by simulating and validating commands, ensuring accurate and reliable rover operations.
  • Honeycomb: Improves understanding of autonomous driving decisions, facilitating mission planning and execution.
