To create a list in Python, you use square brackets [] and include the elements (values) that you want separated by commas ,. Each element must be of the same type, otherwise it becomes a list instead of an array (see in the next section for the definition of a list).

Records

A record is used to store multiple values of different data types to represent a single entity. For example, a record of a person can include their name (string), age (integer), city (string). These attributes are called Keys, and the values that the store are called Values. In each record, the name of the Key must be unique.

In Python, we use dictionaries to implement records.

Dictionaries in Python are lists of Key:Value pairs. This is a very powerful datatype to hold a lot of related information that can be associated through keys. The main operation of a dictionary is to extract a value based on the key name. Unlike lists, where index numbers are used, dictionaries allow the use of a key to access its members. Dictionaries can also be used to sort, iterate and compare data.

Dictionaries are created by using braces ({}) with pairs separated by a comma (,) and the key values associated with a colon (:).

Sequential Files

A sequential file is a type of file that stores data in a linear, sequential order. A program uses a file by opening the file (with the intention of either reading or writing content) and closing the file when it is done. A plain .txt file is commonly used to store sequential data like so:

temperature_logs.txt

27
23
21
18
15
23
29
35

In Python, you can work with sequential files using the built-in open() function to open a file in various modes, such as read ('r'), write ('w'), or append ('a').

Note that in the examples below, we don't have to explicitly use the close() function to close an open file. In Python, when you use the with open(...) as ... statement to open a file, it automatically takes care of closing the file when the block is exited.

Trees

Trees are a type of graph data structure which consists of edges (lines) and one or more nodes (circles). They begin with a single 'root' node expanding downwards into 'children' nodes before ending at the bottom-most 'leaf' nodes. Groups of connected nodes within a tree can be considered as a sub-tree. Like arrays, trees are only store one data type.

   Best way to imagine this data structure is to picture an upside down tree with the root at the top and leaves at the bottom.

Each node has its own particular data value(s) that it stores. Depending on the type of tree, the data will either always be ordered or unordered.

 

The folder structure used to organise the files on your computer uses a tree-like structure starting from the root node 'Macintosh HD' before splitting into 'Applications', 'Library', 'System' and 'Users'. 'Users' has only one node 'martinmadrid' which has its own subtree that splits into 'Desktop', 'Documents', 'Downloads', 'Movies', 'Music', 'Pictures' and 'Public'.

An Application of Trees: Binary Search Trees

Binary Search:

A Binary Search is a standard algorithm that is used to find a number in a sorted set of numbers. This approach to searching uses a 'divide and conquer' algorithm where it repeatedly divides the range of numbers in half until it finds the number or there are no numbers left.

A Binary Search Tree is a type of ordered tree where:

  • Each parent node has 2 children (left and right)

    • All values on the left are less than the parent

    • All values on the right are greater than the parent

  • These rules apply for all nodes in the tree

    • Leaf nodes at the bottom have null children where a node doesn't exist
