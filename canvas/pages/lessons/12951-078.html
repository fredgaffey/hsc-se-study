How to Answer Multi-Select Questions

Procedure:

  1. Read the question carefully and determine the criteria for an option to be correct.
  2. Analyse any provided stimulus.
  3. Read and select options that look like they could be an answer.
  4. Re-read the question again and ensure the options you've selected are correct and that you haven't missed any correct answers.

Question Breakdown & Tips and Tricks

Question: What are key characteristics of supervised learning models in machine learning? (2 marks)

Step 1. Read the question and determine criteria for option to be correct

To determine the criteria which we will use to asses if an option is correct, ask the following questions:

  1. What is the topic/content area? In this case, the topic area is models in machine learning, specifically supervised learning models. Revise 3.3 ML Training Models, if needed.
  2. What are we required to do? Since this is a multi-select question, we need to select one or more checkboxes. Specifically, any option that is a key characteristic of supervised learning models need to be checked. You need to recall everything you know about machine learning models to figure out what is and isn't a feature of supervised learning.

This question doesn't have any provided stimulus, so we skip step 2

Step 3. Select options that satisfy the criteria in the question

We need to read each question and decide if it's a key features of supervise machine learning.

 

 1) Used for spam detection.

Step 3.1 — Assess Option 1 (Correct)

Supervised machine learning is used for models that detect spam.

 

2) Requires labeled datasets for training.

Step 3.2 — Assess Option 2 (Correct)

Supervised learning specifically requires data to be labeled before starting, so this is definitely an option to tick.

 

 3) Uses a trial and error learning approach.

Step 3.3 — Assess Option 3 (Incorrect)

This option is not correct since the trial and error learning approach is used in reinforcement learning, not supervised learning.

 

 4)  Can use linear regression as an algorithm.

Step 3.4 — Assess Option 4 (Correct)

There are a range of algorithms that supervised learning uses, and linear regression is one of them so this option is correct.

 

 5) Can use hierarchical clustering as an algorithm.

Step 3.5 — Assess Option 5 (Incorrect)

Hierarchical clustering is not an algorithm supervised learning uses. It's more used in unsupervised learning.

 

 6) Used for customer segmentation and anomaly detection.

Step 3.6 — Assess Option 6 (Incorrect)

Supervised learning is not used for customer segmentation and anomaly detection. That's more unsupervised learning.

 

Step 4 — Read the questions again to confirm your answers are correct.

Just glance over the options one last time and make sure you haven't misread any.

Marking Criteria (from the perspective of a marker)

 

How do I get full marks?

  • These questions are normally auto-marked meaning the only way to get full marks is by selecting all the correct checkboxes. If you struggle with this question, you should revise 3.3 ML Training Models.

I'm completely stuck. How do I maximise my marks? 

  • Don't leave the question blank. Try and select some boxes to see if you can get at least five correct which will give you one mark which is better than 0. After this, flag the question so you can come back to it after you finish the rest of the exam, hopefully with a a fresh pair of eyes to retry the question.
