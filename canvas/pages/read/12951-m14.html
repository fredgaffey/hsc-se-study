APIs

Q1. Describe the role and importance of APIs in modern software development. (3 marks)

 

High-Band Sample Answer:

An Application Programming Interface (API) acts as an intermediary layer that allows two software applications to communicate using a set of defined protocols. In modern development, APIs are essential for modularisation, enabling developers to integrate third-party services (like Stripe for payments or Google Maps for location) without writing the underlying code. This speeds up the Software Development Life Cycle (SDLC) and ensures consistency across different platforms.

Data Backup

Q2. Describe the process and necessity of programmed data backup. (3 marks)

 

High-Band Sample Answer:

Programmed data backup is the automated process of copying data to a secondary storage medium (e.g., off-site cloud storage or NAS) at scheduled intervals. It is a critical component of contingency planning, ensuring data integrity and availability in the event of hardware failure, cyber-attacks (like ransomware), or accidental deletion. By automating the process, developers reduce the risk of human error and ensure a reliable Recovery Point Objective (RPO).

Web Protocols

Q3. Investigate and describe the function of web protocols and their ports, including DNS and TCP/IP. (5 marks)

 

High-Band Sample Answer:

Web protocols provide the rules for data exchange across a network. TCP/IP is the fundamental suite; IP handles the addressing and routing of packets, while TCP ensures reliable delivery by establishing a connection and checking for errors. DNS (Domain Name System) functions as the "phonebook" of the internet, translating human-readable URLs (e.g., education.nsw.gov.au) into machine-readable IP addresses, typically operating on Port 53. Together, these allow data to be sent to the correct destination and reassembled accurately at the application layer.

Machine Learning

Q4. Assess the models of training Machine Learning (ML), including supervised, unsupervised, semi-supervised, and reinforcement learning. (8 marks)

 

High-Band Sample Answer:

The choice of training model depends heavily on the available data and the desired outcome. Supervised learning is highly effective for classification (e.g., spam filters) as it uses labelled datasets to map inputs to known outputs. In contrast, unsupervised learning is superior for pattern discovery in unlabelled data, such as market segmentation. Semi-supervised learning offers a pragmatic middle ground, using a small amount of labelled data to guide the process of a larger unlabelled set, reducing the high cost of data labelling. Finally, reinforcement learning is unique as it relies on a 'reward/penalty' system (e.g., in autonomous vehicle navigation or gaming AI). While supervised learning is more predictable, reinforcement learning is better suited for dynamic environments where the 'correct' path isn't known in advance.

 

Ethics

Q5. Investigate the effect of human and dataset source bias in the development of ML and AI solutions. (4 marks)

 

High-Band Sample Answer:

Bias in AI is often a reflection of the humans who create it or the data used to train it. Dataset source bias occurs when the training data is not representative of the real-world population (e.g., facial recognition systems trained primarily on one ethnicity). Human bias can manifest during the "feature selection" phase, where developer prejudices influence which data points the algorithm deems important. These biases lead to unfair outcomes, such as discriminatory hiring practices or biased credit scoring, highlighting the legal and ethical necessity for algorithmic transparency and diverse datasets in modern software engineering.

Defensive Data Input

Question (3 marks)

Design and implement code using defensive data input handling (validation, sanitisation, error handling).

Marking Criteria

Criteria Marks
Clearly describes all three: validation, sanitisation, and error handling with technical precision. 3
Describes two elements or provides a general overview of defensive coding. 2
Identifies one element or provides a basic definition. 1

Response A (Mid Band – likely 2–3 marks)

You should check what the user types. Use an if statement to make sure it's a number and not a word so the program doesn't crash.

Response B (Low Band – likely 1–2 marks)

Defensive coding involves validation (ensuring input meets criteria like length/type), sanitisation (stripping harmful characters like <script> tags to prevent SQL injection), and error handling (using try/except blocks) to manage unexpected inputs gracefully without crashing.

Secure Code

Question (4 marks)

How would you protect user file and hardware from file attacks and side-channel attacks.

Marking Criteria

Criteria Marks
Comprehensive explanation of both file attacks and side-channel attacks with mitigation strategies. 4
Explains both types of attacks but lacks detail on hardware/file protection. 2–3
Basic identification of one attack type. 1

Response A (Mid Band)

To prevent file attacks, developers must implement strict file-type verification and 'sandboxing' to isolate uploaded content. Side-channel attacks exploit physical outputs like power consumption or electromagnetic leaks (e.g., timing attacks). Protection involves using 'constant-time' algorithms and hardware shielding to ensure the CPU doesn't leak data patterns during processing.

Response B (Low Band)

File attacks happen when a hacker uploads a virus. Side-channel attacks are when they look at how much power the computer uses or the sound the CPU makes to steal passwords. You should use encryption.

Discussion Prompts

  • What real software examples could improve these?

  • Why is Response B more informative than A?

  • What elements are missing that would push this to full marks?

Implementation Methods

Question (3 marks)

Distinguish between parallel and phased implementation methods when deploying a new software system.

Marking Criteria

Criteria Marks
Clearly distinguishes between both methods, identifying specific characteristics of each. 3
Describes both methods but lacks a clear distinction or technical detail. 2
Identifies one method or provides a general definition of implementation. 1

Response A (Mid Band)

Parallel involves running the old and new systems simultaneously, ensuring a fallback if the new system fails, though it is resource-heavy. In contrast, phased implementation introduces the new system in stages (e.g., module by module), allowing the organisation to adjust to changes gradually without the cost of running two full systems.

Response B (Low Band)

Parallel is when you run both systems at once. Phased is when you do it in stages. Direct is just turning the old one off and the new one on.

Discussion Prompts

  • What software-specific detail could improve Response A?

  • Why might Response B only get 1 mark?

  • Which words or examples would move Response A to 3 marks?

Version Control

Marking Criteria

Criteria Marks
Provides a detailed explanation of version control benefits (e.g., branching, merging, auditing). 3

Response A (Mid Band)

Version control is vital for collaboration as it allows for branching, where developers work on features independently. It prevents code overwrites through merging and provides a 'source of truth' with an audit trail, allowing teams to revert to stable versions if bugs are introduced.

Data Packets

Question (3 marks)

Describe the structure and role of data packets in the transmission of data over the internet.

Marking Criteria

Criteria Marks
Accurately describes the structure (header/payload) and the role of packets in transmission. 3
Provides a general description of packets without specific structural detail. 2
States that data is broken into pieces for the internet. 1

Response A (Mid Band)

Data is segmented into packets, each containing a header (source/destination IP, sequence number) and a payload (the actual data). These packets are routed independently via TCP/IP and reassembled at the destination, where the sequence numbers ensure data integrity if packets arrive out of order.

Response B (Low Band)

Data is broken into packets. They have the address on them and travel through routers until they get to the destination and join back together.

Discussion Prompts

  • Which response describes role better?

  • Which is more specific to software operations?

  • What does a high-band response look like?

Load Times

Question (4 marks)

Propose and justify two methods a developer could implement to improve the load times of a web application.

Marking Criteria

Criteria Marks
Proposes two valid methods and provides a strong justification for each (e.g., latency, file size). 4
Proposes two methods with limited justification, or one method with a strong justification. 2–3
Lists one or two general ideas for making a website faster. 1

Response A (Mid Band – likely 4 marks)

First, implement image compression and lazy loading to reduce the initial payload size and latency. Second, use a Content Delivery Network (CDN) to cache assets on servers closer to the user's geographic location. This minimises 'hops' across the network, significantly reducing the Time to First Byte (TTFB).

Response B (Low Band)

You should make the images smaller so they download faster. You could also use a faster server so the computer doesn't have to wait as long to get the files.

Discussion Prompts

  • What parts of A show justification rather than just description?

  • How could both responses add more software context?

  • What would a high-band structure for this question look like?

Webserver

Question (3 marks)

Outline the role of webserver software in managing a back-end web request.

Marking Criteria

Criteria Marks
Clearly outlines the role, including listening for requests, processing, and returning responses. 3
Describes the general function of a webserver in a client-server relationship. 2
Identifies that a webserver "hosts" a website. 1

Response A (Mid Band)

Webserver software acts as an intermediary that 'listens' for HTTP/HTTPS requests on specific ports. It handles the request-response cycle by retrieving static files or passing dynamic requests to a back-end script (like Python or PHP), then returning the appropriate status code (e.g., 200 OK) and data to the client.

Response B (Low Band)

The webserver software (like Apache) sits on the computer and waits for someone to ask for a page. When they do, it finds the file and sends it back to their browser.

Discussion Prompts

  • What kinds of technologies could be named to improve these answers?

  • Why is Response A more effective than B?

Neural Network

Question (5 marks)

Discuss the use of neural networks in designing machine learning solutions, referencing their architecture and learning process.

Marking Criteria

Criteria Marks
Comprehensive discussion covering architecture (layers/neurons) and the learning process (weights/backpropagation). 5
Describes architecture and the general idea of training with some technical detail. 3–4
Basic description of a neural network or identification of its layers. 1–2

Response A (Mid Band)

Neural networks utilise an architecture of interconnected layers (input, hidden, and output). Each connection has a weight that determines its influence. During training, the model uses backpropagation and gradient descent to adjust these weights based on the error detected in the output, allowing the system to 'learn' and improve its predictive accuracy over time.

Response B (Low Band)

Neural networks are like a brain. They have layers that process data. The more layers you have, the 'deeper' the learning is, which is why it's called deep learning.

Discussion Prompts

  • What makes A stronger than B?

  • What kind of technical information could be added to improve the answers?

  • How could A more clearly show the process of refinement?

Visual Essay Planning

 Give a complex extended response.
 In groups, sketch a mind-map or storyboard for a high-band response before writing.

Your goal: Ensure every "arm" of your mind-map connects a syllabus point to an impact (Individual, Society, or Environment).

Response 1

Stimulus and Question

Stimulus 

By 2030, it is estimated that 30% of hours worked globally could be automated. While this promises a 'Fourth Industrial Revolution' of efficiency, it also threatens to widen the gap between those who own the technology and those whose skills are displaced.

Extended Response Question (8 marks)

Assess the impact of automation on the individual, society, and the environment.

Scaffold

Range Criteria
7–8 Marks Provides a comprehensive assessment of automation's impact across all three areas (Individual, Society, Environment). Uses specific terminology and addresses all syllabus points with balanced, critical judgement.
5–6 Marks Describes several impacts of automation with some assessment. Covers most syllabus points but may lack depth in one area (e.g., environment).
3–4 Marks Outlines basic impacts of automation. Response may be more descriptive than evaluative.
1–2 Marks Identifies one or two general effects of automation (e.g., "robots take jobs").

 

Before you start writing, your group must map the following onto your poster:

  1. The Center: The core question (Impact of Automation).

  2. The Branches: The five syllabus dot points (Safety, Disability, Employment Skills, Environment/Waste, Wealth).

  3. The Links: Use different colours to show if an impact is Positive (+) or Negative (-).

  4. The "Assessment" Keywords: Words like Crucial, Detrimental, Mitigated by, or Enhanced.

 

High-Band Sample Answer (For Deconstruction)

Automation represents a paradigm shift in software engineering, moving from manual logic to autonomous systems. Its impact is multifaceted, offering significant gains in efficiency while presenting deep ethical and social challenges.

Individual Impact: Safety and Accessibility Automation significantly improves individual safety by removing humans from "Dull, Dirty, or Dangerous" tasks (e.g., robotic inspections of high-voltage power lines). Furthermore, for people with disability, automated software (like AI-driven screen readers or autonomous mobility aids) provides unprecedented independence, allowing for greater participation in the workforce and society.

Social Impact: Employment and Wealth The nature of employment is shifting; while manual roles are displaced, there is an increased demand for "high-order" skills in software maintenance, data analysis, and ethical oversight. However, without proactive policy, this risks a negative impact on the economy and distribution of wealth, as the financial gains of automation may concentrate among tech owners, potentially increasing the "digital divide" and socio-economic inequality.

Environmental Impact: Efficiency and Waste From an environmental perspective, automation enhances production efficiency, using sensors and real-time data to minimise raw material usage. However, the hardware required for these systems contributes to e-waste, and the massive energy consumption of data centres required to run complex ML models presents a new environmental challenge that engineers must address through "Green Code" practices.

Conclusion Ultimately, while automation is a tool for immense social good and environmental precision, its success depends on a transition strategy that prioritises the upskilling of workers and the equitable distribution of its economic rewards.
