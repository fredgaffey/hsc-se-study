  Content

 The Object-Oriented Paradigm

Object-oriented programming (OOP) is a programming paradigm that structures computer code using the concept of objects, making the code easier to understand and manage. Instead of just writing lines of instructions one after the other (procedural programming), we organise our code into special groups called classes. Think of classes as templates or blueprints for creating specific types of objects.

An object is a bit like a playable character in a multiplayer video game.

All players have data (attributes) that are associated with them:

  • Gamertag
  • Position
  • Health Stats
  • Attack Stats
  • Defence Stats

Players also have actions (methods) to handle specific tasks that affect their own attributes or the attributes of other players:

  • Move up/down/left/right
  • Heal
  • Deal damage
  • Block attack

Players can also spawn (instantiation) multiple times depending on how many users join the game, all with the same set of methods and attributes.

The game programmer can also stop people from cheating in the game by seeing the current coordinate position of all players. The programmer achieves this by keeping the position attribute private to the player themselves (encapsulation), so that players can't access another player's position.

We may also want different subtypes of players (inheritance), like heroes, villains, healers, and demons.

Overall, OOP helps us keep things organised and makes it easier to reuse and fix our code. It's a bit like building with Lego blocks – you have different pieces that fit together to create something bigger (your program).

A note on terminology between Procedural Programming and Object Oriented Programming. In classes,

  • Variables are called Attributes
  • Functions/Procedures are called Methods

 

 Procedural Programming vs Object-Oriented Programming

The main difference between procedural programming and object-oriented programming is in their fundamental approach to organising code and data.

In procedural programming, the code is organised around procedures or functions, with a focus on the sequential execution of these procedures to achieve a task. Data is often global and can be accessed from anywhere in the program, leading to potential issues with data integrity and code maintenance.

On the other hand, object-oriented programming (OOP) organises code around objects, which encapsulate both data and behaviour. Objects are instances of classes, which serve as blueprints defining the structure and behaviour of objects. OOP emphasises modularity, encapsulation, inheritance, and polymorphism, allowing for more organised, reusable, and easier-to-maintain code compared to procedural programming.

In summary, procedural programming revolves around functions or procedures, while object-oriented programming revolves around objects and classes.
