  Content

 

Definitions and Basic Concepts

Open Control Systems (Open Loop Systems): Open control systems operate without feedback. Rather, these perform their functions based solely on input data and a pre-set sequence of operations

Closed Control Systems (Closed Loop Systems): Closed control systems used feedback to control their operations. They continuously monitor the output and adjust it by comparing it to a desired set point via a feedback loop. This process helps in maintaining the desired level of performance despite external disturbances

 

Algorithmic Patterns

Open Loop Systems:

The algorithm in an open loop system generally will follow a straightforward sequence:

  1. Receive data input
  2. Process the input based on pre-defined settings or configurations
  3. Output the result directly without and feedback consideration

Closed Loop Systems:

Closed loop systems incorporate feedback to adjust their behaviour dynamically:

  1. Set the goal, decide what you want the output to be
  2. Continuously measure the actual output of the system
  3. Check the difference between the desired output and the actual output
  4. Use the difference to make adjustments. If the actual output is too low, increase it; if its too high, decrease it
  5. Repeat until the desired goal is met

Applications

Examples of Open Loop Systems may include:

  • Simple household appliances like toasters and microwave ovens,
  • Washing machines,
  • Heating elements where precision is not critical.

Examples of Closed Loop Systems may include:

  • Automotive systems like cruise control and advanced breaking systems,
  • Industrial automation systems, including robotics and assembly lines,
  • Aerospace applications like autopilot and altitude control,
  • Home heating and air conditioning systems for maintaining temperature.
