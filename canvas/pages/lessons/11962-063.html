Syllabus
Develop, modify and apply algorithms to control a mechatronic system

  Learning Intention and Success Criteria

Learning Intention - Students will:

  • Gain an understanding of the key components and operations of mechatronic systems.

Success Criteria - Students can:

  • Create and modify algorithms to effectively control a mechatronic system's operations.
  • Evaluate the performance of their algorithms in practical mechatronic system scenarios.

  Content

Algorithms are just as important for mechatronics as they were in the units before, you will need to be able to use and understand algorithms in order to design practical mechatronic systems.

Challenges:  

In this game, the VR Robot starts in the center of the Number Grid City. The object of the game is to drive the VR Robot to grid 0 to pick up a secret package, then make a delivery to a randomly assigned number grid. The robot can only drive in the directions parallel to the x-axis or parallel to the y-axis. Can you successfully drive the VR Robot to deliver the secret package to the destination number grid?

Level 1: Create an algorithm to drive the VR Robot to grid 0, then to an assigned grid randomly selected from 1 to 9.

  • Use a variable to store the randomly selected number.
  • Print the variable value to the Print Console to show the assigned grid number.
  • Use the Pen on the robot to draw the delivery path using the variable to determine the drive distance parallel to the x-axis.
  • Use pen.set_pen_color_rgb() to fill in grid 0 and the assigned grid.

Level 2: Create an algorithm to drive the VR Robot to grid 0, then to an assigned grid randomly selected from 20 to 29.

  • Use a variable to store the randomly selected number.
  • Print the variable value to the Print Console to show the assigned grid number.
  • Use the Pen on the robot to draw the delivery path using a variable to determine the drive distance in the directions parallel to the x-axis. Use 400mm as the distance to drive parallel to the y-axis.
  • Use pen.set_pen_color_rgb() to fill in grid 0 and the assigned grid.

Level 3: Create an algorithm to drive the VR Robot to grid 0, then to an assigned grid randomly selected from 1 to 99.

  • Use a variable to store the randomly selected number.
  • Print the variable value to the Print Console to show the assigned grid number.
  • Use the Pen on the VR Robot+ to draw the delivery path using variables to determine the drive distances in the directions parallel to the x-axis and y-axis.
  • Use pen.set_pen_color_rgb() to fill in grid 0 and the assigned grid.
