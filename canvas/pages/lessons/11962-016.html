Identify procedures and functions in an algorithm

  Learning Intention and Success Criteria

Learning Intention - Students will:

  • recognise and understand the use of procedures and functions within an algorithm, including their roles and purposes.

Success Criteria - Students can:

  • Accurately identify procedures and functions in a given algorithm.
  • Differentiate between procedures and functions based on their roles and purposes.
  • Understand the parameters and return values associated with functions.
  • Recognise the importance of modularisation and code reusability achieved through procedures and functions.
  • Apply knowledge of procedures and functions to create or improve an algorithm.

  Content

Procedures and functions are both types of subroutines and are important components of an algorithm, allowing for modularisation and code reusability. They help break down complex tasks into smaller, manageable units.

Both procedures and functions help to break down and divide complex algorithms into smaller and more manageable units that are easier to understand and maintain. They are used to organise code into logical sections and can be called multiple times within a program to prevent code duplication (repeated lines code).

Although procedures and functions serve similar purposes, there are some key differences between the two.

 

 Key Terminology

  • Functions - Blocks of code that take input(s), perform a specific task, and return a value. The primary purpose of a function is to produce a value based on the inputs provided, which can then be used in other parts of the program.
  • Procedures -Also known void functions, procedures are blocks of code that take input(s), perform a specific task but do not return a value. The primary purpose of a function is to only execute commands.

 

 

Python Example

Here's a simple Python algorithm that uses both procedures and functions.

In this example, we have two main components: a function and a procedure.

  1. Function - greet(name):

    • A function is a block of code that takes input(s), performs a specific task, and returns a value.
    • In this case, the greet() function takes a single input name and returns a formatted string with a greeting message.
    • Functions are identified by the def keyword, followed by the function name, parameters in parentheses, and a colon.
    • Functions have a return statement, which specifies the value to be returned to the caller.

  2. Procedure - display_greeting(greeting):

    • A procedure, also known as a subroutine or void function, is a block of code that performs a specific task but does not return a value.
    • In this example, the display_greeting() procedure takes a single input greeting and prints the greeting message to the console.
    • Like functions, procedures are identified by the def keyword, followed by the procedure name, parameters in parentheses, and a colon.
    • Procedures do not have a return statement

You can identify procedures and functions in a Python algorithm by looking for the def keyword and checking for the presence or absence of a return statement. Functions return a value, while procedures do not.
