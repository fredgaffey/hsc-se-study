## 2. Managing Load Times (SA, TKS2025)

*Source: TKS 2025*

**Stimulus:**

A team is developing a web application that is experiencing long load times. They observe that:

-   The application uses many large image files
    
-   It includes multiple external JavaScript and CSS files
    
-   The server reprocesses the same database queries for every user request

#### Part A — –/2 marks  `SHORT`

Outline TWO methods the team could implement to improve the load times of the web application.

*Word limit: 40*

**Your answer:**

_(not answered)_

**Marking criteria:**
- [2] Correctly outlines two methods the team could implement to improve the load times of the web application.
- [1] Correctly outlines one methods the team could implement to improve the load times of the web application.

**Sample answer:**

Any two of the three:

-   Compress the image files to reduce their size and speed up loading.
    
-   Combine JavaScript and CSS files to reduce the number of HTTP requests.
    
-   Implement server-side caching to store and quickly serve frequently accessed content without reprocessing each request.
