Programming for the Web: Backend and Beyond

While the frontend creates the visual experience for users, the backend is the invisible engine powering web applications. This cycle dives deep into the architecture, tools, and processes that run on the server side, ensuring applications are dynamic, secure, and scalable.

Throughout this cycle, we will cover the following key areas:

  • The fundamental role of backend development in managing data, security, and the overall success of a web application.
  • The lifecycle of a web request and the interplay between webservers, frameworks, objects, libraries, and databases.
  • The use of scripting languages, specifically shell scripts, for automating server-side tasks.
  • Database interaction using SQL and Object-Relational Mapping (ORM) to retrieve and manipulate stored data.
  • Best practices for collaboration between frontend and backend teams.
  • The design and implementation of Progressive Web Apps (PWAs) with a focus on UI/UX, accessibility, and inclusivity.

2.15 Backend Development

Assess the contribution of back-end web development to the success of a web application.

 While the front end is what users see, the back end is the engine that powers the application. This page explores how the back end manages data, security, and scalability to ensure the success of modern web applications.
2.16 Web Requests

Observe and describe the back-end process used to manage a web request, including:

  • role of webserver software
  • web framework
  • objects
  • libraries
  • databases
 When you click a link or submit a form, a complex series of events happens behind the scenes. This page breaks down the back-end process, exploring how webservers, frameworks, objects, libraries, and databases work together to manage requests and deliver content.
2.17 Scripting Languages

Develop a web application using an appropriate scripting language with shell scripts to make files and directories, and searching for text in a text file.

 This lesson introduces shell scripting as an interpreted command-line scripting language used to automate backend tasks in web development, including creating files and directories, managing data, and searching text within files.
2.18 Web-Based Databases

Apply a web-based database and construct script that executes SQL, including:

  • selecting fields
  • incorporating ‘group by’
  • common SQL queries
  • constraints using WHERE keyword
  • table joins

This page provides an overview of SQL, covering its standard syntax, various operation types (Retrieval, Manipulation, Definition, and Control), and its role as the universal language for relational databases.
2.19 Object-Relational Mapping

Compare Object-Relational Mapping (ORM) to SQL.

Object-Relational Mapping (ORM) is a programming technique that acts as a bridge between your object-oriented code and your relational database, letting you interact with data without writing raw SQL.
2.20 Collaborative Work Practises

Describe how collaborative work practices between front-end and back-end developers improve the development of a web solution.

Effective front-end and back-end collaboration relies on clear communication, efficient integration and shared responsibility. By using collaborative tools and conducting joint debugging both teams can reduce errors and speed up development.
2.21 Progressive Web Apps

Design, develop and implement a progressive web app (PWA), including:

  • The application of design and user interface (UI) and user experience (UX) principles of font, colour, audio, video and navigation
  • A UI that considers accessibility and inclusivity

Progressive Web Apps (PWAs) combine web and native app experiences to deliver fast, installable, and offline-capable applications. Designing an effective PWA also requires careful attention to UI/UX principles, accessibility, and inclusivity to ensure the app is usable and welcoming for all users across any device.
