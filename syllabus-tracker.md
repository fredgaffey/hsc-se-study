## Programming for the web (WEB)

**Data transmission using the web**

- ⬜ **WEB-1** Explore the applications of web programming  
  _incl. interactive website/webpages; e-commerce; progressive web apps (PWAs)_
- ⬜ **WEB-2** Investigate and practise how data is transferred on the internet  
  _incl. data packets; internet protocol (IP) addresses, including IPv4; domain name systems (DNS)_
- ⬜ **WEB-3** Investigate and describe the function of web protocols and their ports  
  _incl. HTTP, HTTPS; TCP/IP; DNS; FTP, SFTP; SSL, TLS; SMTP, POP 3, IMAP_
- ⬜ **WEB-4** Explain the processes for securing the web  
  _incl. Secure Sockets Layer (SSL) certificates; encryption algorithms; encryption keys; plain text and cipher text; authentication and authorisation; hash values; digital signatures_
- ⬜ **WEB-5** Investigate the effect of big data on web architecture  
  _incl. data mining; metadata; streaming service management_

**Designing web applications**

- ⬜ **WEB-6** Investigate and explain the role of the World Wide Web Consortium (W3C) in the development of applications for the web  
  _incl. Web Accessibility Initiative (WAI); internationalisation; web security; privacy; machine-readable data_
- ⬜ **WEB-7** Model elements that form a web development system  
  _incl. client-side (front-end) web programming; server-side (back-end) web programming; interfacing with databases that are based on Structured Query Language (SQL) or non- SQL_
- ⬜ **WEB-8** Explore and explain the influence of a web browser on web development, including the use of developer (dev) tools
- ⬜ **WEB-9** Investigate cascading style sheets (CSS) and its impact on the design of a web application  
  _incl. consistency of appearance; flexibility with browsers or display devices; CSS maintenance tools_
- ⬜ **WEB-10** Investigate the reasons for version control and apply it when developing web application
- ⬜ **WEB-11** Explore the types and significance of code libraries for front-end web development  
  _incl. frameworks that control complex web applications; template engines; predesigned CSS classes_
- ⬜ **WEB-12** Explain the use and development of open-source software in relation to web development
- ⬜ **WEB-13** Investigate methods to support and manage the load times of web pages/applications
- ⬜ **WEB-14** Research, experiment with and evaluate the prevalence and use of web content management systems (CMS)
- ⬜ **WEB-15** Assess the contribution of back-end web development to the success of a web application
- ⬜ **WEB-16** Observe and describe the back-end process used to manage a web request  
  _incl. role of webserver software; web framework; objects; libraries; databases_
- ⬜ **WEB-17** Develop a web application using an appropriate scripting language with shell scripts to make files and directories, and searching for text in a text file
- ⬜ **WEB-18** Apply a web-based database and construct script that executes SQL  
  _incl. selecting fields; incorporating ‘group by’; common SQL queries; constraints using WHERE keyword; table joins_
- ⬜ **WEB-19** Compare Object-Relational Mapping (ORM) to SQL
- ⬜ **WEB-20** Describe how collaborative work practices between front-end and back-end developers improve the development of a web solution
- ⬜ **WEB-21** Design, develop and implement a progressive web app (PWA)  
  _incl. the application of design and user interface (UI) and user experience (UX) principles of font, colour, audio, video and navigation; a UI that considers accessibility and inclusivity_

- ⬜ **AUTO-2** Distinguish between artificial intelligence (AI) and ML
- ⬜ **AUTO-3** Explore models of training ML  
  _incl. supervised learning; unsupervised learning; semi-supervised learning; reinforcement learning_
- ⬜ **AUTO-4** Investigate common applications of key ML algorithms  
  _incl. data analysis and forecasting; virtual personal assistants; image recognition_
- ⬜ **AUTO-5** Research models used by software engineers to design and analyse ML  
  _incl. decision trees; neural networks_
- ⬜ **AUTO-6** Describe types of algorithms associated with ML  
  _incl. linear regression; logistic regression; K-nearest neighbour_

**Programming for automation**

- ⬜ **AUTO-7** Design, develop and apply ML regression models using an OOP to predict numeric values  
  _incl. linear regression; polynomial regression; logistic regression_

- ⬜ **AUTO-9** Assess the impact of automation on the individual, society and the environment  
  _incl. safety of workers; people with disability; the nature and skills required for employment; production efficiency, waste and the environment; the economy and distribution of wealth_

  _incl. psychological responses; patterns related to acute stress response; cultural protocols; belief systems_
- ⬜ **AUTO-11** Investigate the effect of human and dataset source bias in the development of ML and AI solutions
