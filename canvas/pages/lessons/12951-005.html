  Introduction

This module will focus on the importance of developing secure software, and how following structured software development steps can ensure the security, reliability, and performance of your programs. In addition to learning about secure development practices, you’ll explore how software design concepts such as confidentiality, integrity, and availability play a crucial role in creating secure systems. The topics in this module will guide you through the software development process, from initial requirements to deployment and maintenance, with a strong emphasis on security. By the end, you’ll also understand how the end user’s capabilities influence secure design features.

  Syllabus

Designing Software

  • Describe the benefits of developing secure software

    Including:
    • data protection
    • minimising cyber attacks and vulnerabilities

  • Interpret and apply fundamental software development steps to develop secure code

    Including:
    • requirements definition
    • determining specifications
    • design
    • development
    • integration
    • testing and debugging
    • installation
    • maintenance

  • Describe how the capabilities and experience of end users influence the secure design features of software

Developing secure code

  • Explore fundamental software design security concepts when developing programming code

    Including:
    • confidentiality
    • integrity
    • availability
    • authentication
    • authorisation
    • accountability

  • Apply security features incorporated into software including data protection, security, privacy and regulatory compliance
