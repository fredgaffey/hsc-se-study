NESA Sentence Starters

HSC Software Engineering · ~25–30 words per mark · ~2 minutes per mark · spelling is not marked, content is

The four moves (every "explain")

Concept → Why / how → Example in the scenario → Effect

  1. [Concept] is ___ / ___ means ___.
  2. This is because ___ / This works by ___.
  3. For example, in this scenario ___.
  4. As a result, ___ / This means that ___ / Therefore ___.

More points

  • One [benefit / risk / way / challenge] is ___.
  • Another [benefit / way] is ___.
  • Furthermore, ___ / In addition, ___.
  • This is important because ___.

Other side (discuss / evaluate)

  • However, ___.
  • On the other hand, ___.
  • A limitation is that ___.
  • This could also lead to ___.

Compare

  • Both ___ and ___ can ___.
  • Whereas ___ does ___, ___ does ___.
  • Unlike ___, ___ ___.
  • For this scenario, ___ is better because ___.

Judgement (evaluate / assess / justify)

  • This is effective because ___.
  • This is limited because ___.
  • Overall, ___ because ___.
  • Therefore, the most suitable ___ is ___.

Question words

8–10 markers: plan 2 min → opening that answers the question → 3 body paragraphs → "Overall… because…". Take a rest break just before them.

Before moving on, check

  • Did I name the concept before giving examples?
  • Is every point linked to the scenario?
  • Covered every part named (TWO / both sides / judgement)?
  • Full sentences, not dot points?
  • Nothing blank. A partial answer still earns marks.
