Syllabus
Represent integers using two’s complement

  Learning Intention and Success Criteria

Learning Intention - Students will:

  • Develop an understanding of two's complement representation and apply it to represent integers in binary.

Success Criteria - Students can:

  • Understand the concept of two's complement representation.
  • Explain the process of converting positive and negative integers to their two's complement form.
  • Accurately convert integers between decimal and two's complement binary representations.
  • Demonstrate the ability to perform arithmetic operations using two's complement binary numbers.

  Content

Two's Compliment is the way in which computers represent positive and negative integers.

Unsigned integers (without Two's Compliment) only represents positive values. This is how you've been introduced to reading Binary in the previous lesson. For example:

01101010 = 106
11101010 = 234

Signed integers (Two's Compliment) represents both positive and negative values where the left-most binary digit (underlined) indicates if the number is positive ('0') or negative ('1'). For example:

01101010 = 106
11101010 = -22

   Notice that by only changing the left-most binary digit means that the entire number has changed (i.e. 106 did not become -106). You will learn to calculate Signed Integers later in the lesson.

 

Number Circle

 Number Circles are used to visually represent how Two's Complement is able to represent negative numbers in Binary. Think about it like a number line where the numbers to the right of the 0 is positive and the numbers to the left of the 0 is negative.

   The number of bits that are used to represent a Decimal number in Binary will have an impact on the largest and smallest numbers that it can represent. Thus, the reason why number circles are used instead of number lines where the values extend to infinity.

 

For example, a hypothetical 3-bit number system shown as a number circle. The Two's Complement system (signed) is represented on the right.

 

 

  Note how the Two's Complement system will always create one more negative number than positive numbers. You'll never find a computer using a 3-bit system in real life, but it makes for a nice example.

 

Converting between Decimal and Signed Binary (Two's Complement)

Converting between Decimal and Signed Binary using Two's Complement is very similar to the process of converting using unsigned numbers. The only difference being the last place value which is now negative instead of positive (i.e. the place value 128 is now -128).
