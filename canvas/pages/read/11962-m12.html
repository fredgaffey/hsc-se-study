3.10 Open & Closed Control Systems

Syllabus
Explore the algorithmic patterns, code and applications for open and closed control systems

  Learning Intention and Success Criteria

Learning Intention - Students will:

  • understand the fundamental concepts and differences between open and closed control systems.
  • explore algorithmic patterns and coding practices used in the development of these systems.

Success Criteria - Students can:

  • identify and describe examples of open and closed control systems in various applications.
  • develop basic algorithms that simulate the behavior of open and closed control systems.
  • analyse and compare the efficiency and applications of these systems in real-world scenarios.

  Content

 

Definitions and Basic Concepts

Open Control Systems (Open Loop Systems): Open control systems operate without feedback. Rather, these perform their functions based solely on input data and a pre-set sequence of operations

Closed Control Systems (Closed Loop Systems): Closed control systems used feedback to control their operations. They continuously monitor the output and adjust it by comparing it to a desired set point via a feedback loop. This process helps in maintaining the desired level of performance despite external disturbances

 

Algorithmic Patterns

Open Loop Systems:

The algorithm in an open loop system generally will follow a straightforward sequence:

  1. Receive data input
  2. Process the input based on pre-defined settings or configurations
  3. Output the result directly without and feedback consideration

Closed Loop Systems:

Closed loop systems incorporate feedback to adjust their behaviour dynamically:

  1. Set the goal, decide what you want the output to be
  2. Continuously measure the actual output of the system
  3. Check the difference between the desired output and the actual output
  4. Use the difference to make adjustments. If the actual output is too low, increase it; if its too high, decrease it
  5. Repeat until the desired goal is met

Applications

Examples of Open Loop Systems may include:

  • Simple household appliances like toasters and microwave ovens,
  • Washing machines,
  • Heating elements where precision is not critical.

Examples of Closed Loop Systems may include:

  • Automotive systems like cruise control and advanced breaking systems,
  • Industrial automation systems, including robotics and assembly lines,
  • Aerospace applications like autopilot and altitude control,
  • Home heating and air conditioning systems for maintaining temperature.

3.11 Autonomous Control

Syllabus
Outline the features of an algorithm and program code used for autonomous control

  Learning Intention and Success Criteria

Learning Intention - Students will:

  • understand the key features of an algorithm and program code used for autonomous control.
  • be able to identify and outline the components that make up an algorithm and program code for autonomous system

Success Criteria - Students can:

  • explain the main features of an algorithm used in autonomous control systems, including input, output, processing, and decision-making steps.
  • describe the structure and elements of program code necessary for autonomous control, such as loops, conditionals, and functions.
  • develop a basic algorithm and corresponding program code that demonstrates autonomous control in a given scenario.
  • test and debug the program code to ensure it performs the intended autonomous functions accurately.
  • evaluate the effectiveness of their algorithm and program code in achieving autonomous control and suggest potential improvements for optimization and efficiency.

  Content

Autonomous control refers to the capability of a system to operate independently, making decisions and performing tasks without human intervention. This involves using sensors, algorithms, and actuators to perceive the environment, plan actions, and execute commands. Autonomous control systems are widely used in various applications, such as self-driving cars, drones, robotics, and industrial automation.

 

Autonomous control algorithms manage mechatronic systems by sensing the system state, calculating the error from a desired setpoint, and computing the required control values. This process repeats continuously in a control loop. The three common types of algorithms are:

On/Off Control (Bang-Bang Control)

Functionality:

  • Turns actuators fully on or fully off based on the system state relative to the desired setpoint.
  • Operates in a binary manner, switching between two extremes.

Strengths:

  • Simple to implement.
  • Suitable for systems where precise control is unnecessary.

Weaknesses:

  • Tends to overshoot or undershoot the setpoint.
  • Can cause oscillations as the system repeatedly hits its limits.

Additional Feature: Hysteresis:

To reduce rapid switching and potential damage to components, a tolerance band around the setpoint is introduced. This creates stability by ensuring the system only activates when deviations exceed a certain threshold.

Proportional Control

Functionality:

  • Adjusts the actuator’s response proportionally to the error (the difference between the system state and the desired setpoint).
  • The larger the error, the stronger the response.

Strengths:

  • Smoother and more refined control compared to on/off systems.
  • Reduces oscillations by varying the strength of the response.

Weaknesses:

  • When the error is small, the control signal may be too weak to move actuators effectively.
  • Can result in steady-state errors, where the system stabilises near, but not exactly at, the setpoint.

PID Control (Proportional-Integral-Derivative)

PID control enhances proportional control by adding two components: integral and derivative control.

Proportional Component (P):

  • Provides immediate adjustments based on the size of the error.

Integral Component (I):

  • Accumulates past errors over time.
  • Helps eliminate steady-state errors by ensuring that small deviations are corrected gradually.

Derivative Component (D):

  • Reacts to the rate of change in error.
  • Dampens overshoot by reducing the control response as the system approaches the setpoint too quickly.

Strengths:

  • Combines the benefits of proportional, integral, and derivative control for precise and stable operation.
  • Adapts to dynamic conditions, correcting both short-term and long-term deviations.

Weaknesses:

  • More complex to configure due to the need to tune proportional, integral, and derivative gains.
  • Can be computationally intensive for some systems.

 

 

Features of an Algorithm for Autonomous Control

 

Sensor Integration

Usage in Autonomous Control: Sensors provide real-time data about the environment. This data is crucial for making informed decisions and executing precise actions.

    •    Data Acquisition: Collecting data from various sensors like GPS, LIDAR and cameras.
    •    Sensor Fusion: Combining data from multiple sensors to create a comprehensive understanding of the environment.

Perception

Usage in Autonomous Control: Perception allows the system to interpret and understand its surroundings, which is essential for safe and efficient operation.

    •    Object Detection and Classification: Identifying and classifying objects in the environment.
    •    Environment Mapping: Creating and updating a map of the surroundings.
    •    Localisation: Determining the system’s position within the map.

Decision Making

Usage in Autonomous Control: Decision-making algorithms determine the best course of action based on the current situation and goals.

    •    Path Planning: Generating an optimal path to the destination, considering obstacles and objectives.
    •    Behaviour Planning: Deciding on high-level actions based on the current situation (e.g., lane changing, stopping).

Control

Usage in Autonomous Control: Control algorithms convert decisions into actionable commands to guide the system’s movement and actions.

    •    Motion Control: Converting path planning into executable commands for actuators (e.g., steering, acceleration, braking).
    •    Trajectory Tracking: Ensuring the system follows the planned path accurately.

Communication

Usage in Autonomous Control: Communication ensures coordination within the system and with external entities, enhancing situational awareness and safety.

    •    Inter-System Communication: Exchanging data between different parts of the system (e.g., sensors, controllers).
    •    External Communication: Interfacing with external systems (e.g., traffic signals, other vehicles).

Safety and Redundancy

Usage in Autonomous Control: Safety mechanisms and redundancy are critical to handle errors and ensure continuous operation in case of failures.

    •    Error Handling: Detecting and responding to errors or failures in the system.
    •    Fail-Safe Mechanisms: Implementing backup systems to maintain control if the primary system fails.

3.12 Design/Develop

Syllabus
Design, develop and produce a mechatronic system for a real-world problem including:
software control
mechanical engineering
electronics and mathematics

  Learning Intention and Success Criteria

Learning Intention - Students will:

  • Students will understand how to design, develop, and produce a mechatronic system for a real-world problem, integrating software control, mechanical engineering, electronics, and mathematics.

Success Criteria - Students can:

  • Students can design a mechatronic system, develop and implement software control, apply mechanical engineering principles, integrate electronics, and utilize mathematics to solve real-world problems.

  Content

 

Software Control

Software Control involves using computer programs to manage, operate and monitor mechanical and electronic system. This includes algorithms, user interfaces and real-time processing that ensure the system operates correctly and efficiently.

Role in Mechatronic Systems:

  • Control Algorithms: Software control implements algorithms that dictate how the system responds to different inputs and conditions. For example, in a robotic arms, software determines the precise movements required to pick up an object.
  • Data Processing: Software processes data from sensors to make real-time decisions. For example, an autonomous vehicle uses software to process data from cameras and LIDAR to navigate safely
  • User Interface: Software provides interfaces for users to interact with the system, such as touch screens or remote controls

 

Applications:

  • Robotics
  • Automation Systems
  • Automotive Systems

Mechanical Engineering

Mechanical Engineering involves using principles of physics, mathematics, and materials science to design, analyse, manufacture, and maintain mechanical systems. This includes the application of these principles to ensure the systems operate efficiently and effectively.

 

Role in Mechatronic Systems:

  • Structural Design: Mechanical engineering provides the structural design and analysis required for mechatronic systems. For example, in a robotic arm, mechanical engineering determines the materials and structural configuration to ensure strength and durability.
  • Dynamics and Kinematics: Mechanical engineers analyze and design the motion of mechanical systems. For instance, they determine the movement and forces in mechanisms, ensuring precise and efficient operation.
  • Thermal Management: Mechanical engineering involves managing the thermal aspects of mechatronic systems. For example, in electronic devices, mechanical engineers design cooling systems to prevent overheating.

 

Applications:

  • Robotics
  • Automotive Systems
  • Aerospace Systems

Electronics

Electronics involves using electrical circuits and components to design and develop devices that manage electrical energy and signals. This includes the development of integrated circuits, microcontrollers, and power electronics that are critical for system functionality.

 

Role in Mechatronic Systems:

  • Circuit Design: Electronics involves designing circuits that control and power mechanical systems. For example, in an autonomous vehicle, electronic circuits manage sensor inputs and motor outputs.
  • Signal Processing: Electronic systems process signals from sensors to make real-time decisions. For instance, electronic circuits in a drone process signals to stabilise and control flight.
  • Power Management: Electronics ensures efficient power management within the system. For example, in a wearable device, electronic circuits manage battery power to extend operational life.

 

Applications:

  • Consumer Electronics
  • Medical Devices
  • Industrial Automation

Mathematics

Mathematics involves using mathematical theories and techniques to model, analyse, and solve problems in various fields. This includes the application of mathematics to ensure accuracy and optimisation in system design and operation.

 

Role in Mechatronic Systems:

  • Modeling and Simulation: Mathematics is used to model and simulate the behaviour of mechatronic systems. For example, mathematical models predict the performance of a robotic system under different conditions.
  • Optimisation: Mathematics is used to optimise the design and operation of systems. For instance, algorithms optimise the path planning for autonomous robots to minimise energy consumption.
  • Control Theory: Mathematical principles underpin control theory, which governs how systems respond to inputs. For example, control algorithms use mathematics to ensure stability and performance in automated systems.

 

Applications:

  • Robotics
  • Telecommunications
  • Engineering Design
