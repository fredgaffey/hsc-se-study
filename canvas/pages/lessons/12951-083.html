Sample Answer

 Question Breakdown & Tips and Tricks

Question: Write a python program that

  • Calculates the average band performance of all the students using the data above.
  • Calculates the average effort rating of the students using the data above.
  • Displays the average band and average effort rating to the output. The average effort rating should be to 2 decimal placed and the average band should be rounded to the nearest whole number.
  • Uses a function to calculate the band.

Step 1. Read the question carefully

When reading the question, it's important to ask these two questions:

  1. What is the topic/content area? This question is testing your python program writing skills. This is under the "Programming with Python" section of your course specs.
  2. What are we required to do? We need write a python program that calculates the average band from all the scores given in the array of dictionaries in the stimulus, calculates the average effort rating in the same way, displays these two to the output and also uses a function to calculate the band. This means the band calculation cannot be in our mainline.

Stimulus:

A school wants to develop a tool to help classes correlate their overall performance with the effort ratings of students. School report data has been placed in python as an array of dictionaries. The exact structure is as below:

students = [
{"name": "Student 1", "effort": 8, "score": 95},
{"name": "Student 2", "effort": 7, "score": 85},
{"name": "Student 3", "effort": 5, "score": 72},
{"name": "Student 4", "effort": 9, "score": 94},
{"name": "Student 5", "effort": 8, "score": 89},
{"name": "Student 6", "effort": 7, "score": 83},
{"name": "Student 7", "effort": 4, "score": 74},
{"name": "Student 8", "effort": 10, "score": 98},
{"name": "Student 9", "effort": 5, "score": 79},
{"name": "Student 10", "effort": 8, "score": 87}
]

Write a python program that

  • Calculates the average band performance of all the students using the data above.
  • Calculates the average effort rating of the students using the data above.
  • Displays the average band and average effort rating to the output. The average effort rating should be to 2 decimal placed and the average band should be rounded to the nearest whole number.
  • Uses a function to calculate the band.

Bands are calculated as follows:
Band 6 (90 – 100)
Band 5 (80 – 89)
Band 4 (70 – 79)
Band 3 (60 – 69)
Band 2 (50 – 59)
Band 1 (0 – 49)

Using the students array above, the output should look like:

Step 2. Analyse the stimulus

There is a lot to unpack in this stimulus.

  • We are given the data structure we will be operation on. We will just copy this into the Python code writing area when we start creating the program.
  • We are also told how to format the output numbers with the average band being the closest whole number and the average effort being to two decimal places.
  • We are also given the guidelines for how to calculate a band from a score. 
  • Finally, we are given a sample output which our program should also replicate in terms of output style and correct values.

Step 3. Draft your response quickly in your head.

Based on the stimulus, we know we need a function to calculate the band given a score so that will go at the top of the program. Then in our main line we will to calculate the averages. It would be wise to use a for loop to iterate over each student and add their band and effort rating to a running total which we can then divide by the number of students at the end to get the average. Finally, we would need to print the values to the output.

Step 4. Create your response using the online HSC python coding tool.

  1. First, copy the array into the input code section of the online HSC writing tool.
  2. Write the calcuate_band function using the conversion criteria provided in the stimulus.
  3. Write the mainline of the program
    1. Initialise the variables you are going to use to track the running totals
    2. Write a for loop that iterates over each student and use the dictionary key access syntax to extract the score and pass it into the calcuate_band function and add the to a running band total. Also extract the effort rating and it to a running total of effort ratings.
    3. After the loop, divide the running totals by the number of students, remembering the round the average_band to the nearest whole number using the round() function.
    4. Then we print out the values using the python f-string formatting syntax to print the average effort rating to 2 decimal places. You don't need to do any formatting for the band since it's already rounded to an integer in the division calculation.

Step 5. Examine your work and make sure it's correct

  1. Click "run" at the top right and make sure you output is identical to the sample output.
  2. Then glance over your code one more time to make sure there are no glaring logic issues such as using ">" instead of ">=".
  3. Add new lines to segment parts of the code the do different things for better readability.

 

Marking Criteria (through the eyes of a marker)

How to get full marks?

  1. The first key phrase is "substantially correct". This means, to get full marks, your code doesn't have to be perfect. If you missed one small thing, you can still get 6/6, so don't stress, just focus on doing your best job. E.g if there was one minor logic error in your band calculation you could very well still get full marks.
  2. The other key phrase is "including all the features". This means you need to complete each of the five dots points to a substantially correct quality. If you don't use a function to calculate band or you don't calculate one of the averages, you will only get 5 marks at most.

I'm completely stuck and not getting anywhere. How do I salvage as many marks as a I can?

  • Don't leave the question blank. If you're totally stuck, there are always some basic things you can do to guarantee at least one or two marks. After this, flag the question so you can come back to it after you finish the rest of the exam, hopefully with fresh ideas to claim a few more marks.
  • You'll notice there is one mark for "showing some understanding of the requirement". This means literally setting up some variables to track totals could get you one mark.
  • If you satisfy 2 or more of the requirements working, that should give you 3-4 marks which is pretty good.
