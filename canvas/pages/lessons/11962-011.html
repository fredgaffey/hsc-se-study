Syllabus
Develop structured algorithms using pseudocode and flowcharts, including the use of subprograms

  Learning Intention and Success Criteria

Learning Intention - Students will:

  • be able to develop structured algorithms using pseudocode and flowcharts, including the use of subprograms, to solve complex computational problems.

Success Criteria - Students can:

  • explain the importance of developing structured algorithms using pseudocode and flowcharts to solve complex computational problems.
  • develop algorithms using pseudocode and flowcharts, including the use of subprograms, to solve different computational problems and apply key programming constructs such as sequence, selection, and iteration.
  • test and debug algorithms to ensure they correctly solve the computational problem and can handle different input values and boundary cases.
  • evaluate the effectiveness of different algorithmic designs, including their efficiency, scalability, and readability, and propose improvements or optimisations to enhance their performance.

Subprograms

Subprograms, also known as functions or procedures, are reusable chunks of code that perform a specific task within a program. They help in breaking down complex problems into smaller, more manageable tasks, improve code readability, and promote modularity. Using subprograms makes it easier to maintain, debug, and update the code.

In Python, subprograms are created using the def keyword, followed by the function name, a pair of parentheses containing any input parameters, and a colon. The code block inside the function is indented. Functions can return the value of one variable using the return statement.

Functions are defined at the top of the Python script, with the mainline in which they are called at the bottom.

These subprograms are then called in the main program underneath all of the function definitions, with the given input parameters (num_1 and num_2). The results are then printed to the console.
