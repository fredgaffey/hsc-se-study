  Content

Regression models are essential tools in machine learning for predicting numerical values based on input data. In this lesson, we explore the development and application of three key regression models—linear regression, polynomial regression, and logistic regression—using an object-oriented programming (OOP) approach. By adopting OOP principles, we can design flexible and reusable models that efficiently handle different types of prediction tasks.

Linear regression helps in modelling relationships between variables through a straight line, while polynomial regression extends this to capture more complex, non-linear relationships. Logistic regression, though commonly associated with classification, is included here to highlight its use in predicting probabilities for binary outcomes. Through these models, you will gain a deeper understanding of how to apply regression techniques to solve real-world problems in a structured, scalable manner.

 

Why use OOP to design models?

Traditionally, regression models can be written in procedural or declarative. However, using OOP, developers can create scalable regression models! This means we can leverage powerful OOP features, including:

  • Scalability – Easily extend models with inheritance.
  • Modularity – Keep data and logic together with encapsulation.
  • Maintainability – Enforce structured models with abstraction.
  • Flexibility – Swap different regression models dynamically using polymorphism.

 

Linear Regression

Linear regression is a supervised learning algorithm that models the relationship between a dependent variable (target) and one or more independent variables (features) by fitting a linear equation to observed data.

Key Equation:

y=β0+β1x1+β2x2+⋯+βnxn+ϵy = \beta_0 + \beta_1 x_1 + \beta_2 x_2 + \dots + \beta_n x_n + \epsilon

Where:

  • yy is the predicted output (dependent variable).
  • x1,x2,…,xnx_1, x_2, \dots, x_n are the input features (independent variables).
  • β0\beta_0 is the intercept, and β1,…,βn\beta_1, \dots, \beta_n​ are the coefficients (slopes) of the model.
  • ϵ\epsilon represents the error term (residuals).

 

Basic Structure for Defining a LinearRegression Class:

  • Attributes: Coefficients, intercept, learning rate, number of iterations.
  • Methods:
    • fit(): Trains the model by calculating optimal coefficients using gradient descent.
    • predict(): Uses the fitted model to predict values for new data.
    • evaluate(): Calculates performance metrics such as Mean Squared Error (MSE).

 

Applications:

  • Predicting housing prices based on features like square footage, number of bedrooms, etc.
  • Forecasting sales figures based on past data.

Polynomial Regression

Polynomial regression is an extension of linear regression where the relationship between the input variables and output is modelled as an nth-degree polynomial.

Key Equation:

y=β0+β1x+β2x2+⋯+βnxn+ϵy = \beta_0 + \beta_1 x + \beta_2 x^2 + \dots + \beta_n x^n + \epsilon

  • The model is still linear in terms of the coefficients, but the features are transformed into polynomial terms.

Basic Structure to Implement Polynomial Regression in OOP:

    • Inherit from LinearRegression to reuse logic for fitting and prediction.
    • Additional Attribute: Degree of the polynomial.
    • Method: transform() that converts input features into polynomial terms.

 

Applications:

  • Modelling non-linear relationships, such as growth curves or natural phenomena like temperature variation.

Logistic Regression

Although its name includes "regression," logistic regression is used for binary classification tasks. It predicts the probability of a binary outcome (e.g., yes/no, 0/1).

p(x)=11+e−(β0+β1x1+⋯+βnxn)p(x) = \frac{1}{1 + e^{-(\beta_0 + \beta_1 x_1 + \dots + \beta_n x_n)

Where:

  • p(x)p(x is the predicted probability.
  • The model uses the sigmoid function to map predictions to a range between 0 and 1.

Basic Structure to Implement Logistic Regression in OOP:

    • Inherit from LinearRegression.
    • Methods: Implement the sigmoid activation and adjust the gradient descent to minimise the cross-entropy loss instead of MSE.

 

Applications:

  • Classifying whether a customer will purchase a product (yes/no).
  • Predicting whether a patient has a disease (0/1).
