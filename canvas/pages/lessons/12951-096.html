  Content

What is Code Optimisation? 

Code Optimisation is the process of improving the performance and efficiency of a program by making it run faster and consuming fewer computational resources. 

Optimisation can be approached in two main ways:

  1. Language-Independent Optimisation: Techniques like reducing algorithmic complexity, eliminating redundant code, or improving data structures can apply to almost any programming language.

  2. Language-Dependent Optimisation: Techniques using language-specific features to enhance performance. 
    For example, Python-specific constructs can make Python code more efficient.

 

Code Optimisation in Python

Recap: Python Peformance

Python is a high-level, interpreted language that executes code line by line rather than compiling it into machine code like C or C++. This makes it slower than compiled languages, which execute directly on hardware.

 Therefore, language-specific optimisation in Python is challenging.

However, as the Python interpreter is written in C, we can leverage many in-built functions implemented in C and optimised for performance. These built-in functions are generally faster than writing equivalent logic manually in Python.

 

1. Use Built-in Functions and Libraries

Python provides highly optimised built-in functions like sum(), max(), min(), sorted(), and map(), which are implemented in C and run significantly faster than manual loops.

2. List Comprehension

In Python, a list comprehension is a concise way to create lists. It’s faster than using a traditional for loop to iterate through a list and apply some operation to each element. This performance boost is because list comprehensions are implemented as C loops internally in Python, making them more efficient than a standard Python loop.

Extension: timeit()

Try write Python code to compare the performance of a traditional for loop with a list comprehension using the timeit module. You will perform multiple trials and calculate the average execution time for both approaches.

Objective

  • Use the timeit() function to measure and compare the execution time of a for loop and a list comprehension.
  • Perform multiple trials to average the times and determine which approach is faster.

 

The timeit() function allows you to time small code snippets. Here’s what each parameter does:

  • stmt: The code you want to time as a string (e.g., "for i in range(10): pass").
  • setup: Optional. Any code that needs to run before timing begins (e.g., importing modules or initialising variables).
  • number: The number of times to run the code. More iterations will give a more stable average.

 

Example usage:

timeit.timeit(stmt="for i in range(10): pass", setup="", number=10000)

Why is this Optimisation Effective in Python?

  1. Fewer Lines of Code: List comprehensions are more concise, which means fewer opportunities for errors and easier maintenance.
  2. Internal Optimisation: Python internally optimises list comprehensions using highly efficient C implementations.
  3. Better Memory Usage: Since list comprehensions are optimised for execution, they tend to use memory more efficiently, reducing the overhead of appending items in loops.
