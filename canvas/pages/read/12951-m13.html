3.7 Regression Models

Syllabus

Design, develop and apply ML regression models using an OOP to predict numeric values, including:

  • linear regression
  • polynomial regression
  • logistic regression

  Learning Intention and Success Criteria

Learning Intention - Students will:

  • Design, develop, and implement machine learning regression models using an object-oriented programming (OOP) approach to predict numeric values, including linear regression, polynomial regression, and logistic regression.

Success Criteria - Students can:

  • Explain the differences between linear, polynomial, and logistic regression.
  • Design classes in Python to represent regression models, using inheritance and encapsulation effectively.
  • Implement OOP-based regression models to solve prediction tasks and assess their performance using appropriate metrics.

  Content

Regression models are essential tools in machine learning for predicting numerical values based on input data. In this lesson, we explore the development and application of three key regression models—linear regression, polynomial regression, and logistic regression—using an object-oriented programming (OOP) approach. By adopting OOP principles, we can design flexible and reusable models that efficiently handle different types of prediction tasks.

Linear regression helps in modelling relationships between variables through a straight line, while polynomial regression extends this to capture more complex, non-linear relationships. Logistic regression, though commonly associated with classification, is included here to highlight its use in predicting probabilities for binary outcomes. Through these models, you will gain a deeper understanding of how to apply regression techniques to solve real-world problems in a structured, scalable manner.

 

Why use OOP to design models?

Traditionally, regression models can be written in procedural or declarative. However, using OOP, developers can create scalable regression models! This means we can leverage powerful OOP features, including:

  • Scalability – Easily extend models with inheritance.
  • Modularity – Keep data and logic together with encapsulation.
  • Maintainability – Enforce structured models with abstraction.
  • Flexibility – Swap different regression models dynamically using polymorphism.

 

Linear Regression

Linear regression is a supervised learning algorithm that models the relationship between a dependent variable (target) and one or more independent variables (features) by fitting a linear equation to observed data.

Key Equation:

y=β0+β1x1+β2x2+⋯+βnxn+ϵy = \beta_0 + \beta_1 x_1 + \beta_2 x_2 + \dots + \beta_n x_n + \epsilon

Where:

  • yy is the predicted output (dependent variable).
  • x1,x2,…,xnx_1, x_2, \dots, x_n are the input features (independent variables).
  • β0\beta_0 is the intercept, and β1,…,βn\beta_1, \dots, \beta_n​ are the coefficients (slopes) of the model.
  • ϵ\epsilon represents the error term (residuals).

 

Basic Structure for Defining a LinearRegression Class:

  • Attributes: Coefficients, intercept, learning rate, number of iterations.
  • Methods:
    • fit(): Trains the model by calculating optimal coefficients using gradient descent.
    • predict(): Uses the fitted model to predict values for new data.
    • evaluate(): Calculates performance metrics such as Mean Squared Error (MSE).

 

Applications:

  • Predicting housing prices based on features like square footage, number of bedrooms, etc.
  • Forecasting sales figures based on past data.

Polynomial Regression

Polynomial regression is an extension of linear regression where the relationship between the input variables and output is modelled as an nth-degree polynomial.

Key Equation:

y=β0+β1x+β2x2+⋯+βnxn+ϵy = \beta_0 + \beta_1 x + \beta_2 x^2 + \dots + \beta_n x^n + \epsilon

  • The model is still linear in terms of the coefficients, but the features are transformed into polynomial terms.

Basic Structure to Implement Polynomial Regression in OOP:

    • Inherit from LinearRegression to reuse logic for fitting and prediction.
    • Additional Attribute: Degree of the polynomial.
    • Method: transform() that converts input features into polynomial terms.

 

Applications:

  • Modelling non-linear relationships, such as growth curves or natural phenomena like temperature variation.

Logistic Regression

Although its name includes "regression," logistic regression is used for binary classification tasks. It predicts the probability of a binary outcome (e.g., yes/no, 0/1).

Key Equation:

p(x)=11+e−(β0+β1x1+⋯+βnxn)p(x) = \frac{1}{1 + e^{-(\beta_0 + \beta_1 x_1 + \dots + \beta_n x_n)

Where:

  • p(x)p(x is the predicted probability.
  • The model uses the sigmoid function to map predictions to a range between 0 and 1.

Basic Structure to Implement Logistic Regression in OOP:

    • Inherit from LinearRegression.
    • Methods: Implement the sigmoid activation and adjust the gradient descent to minimise the cross-entropy loss instead of MSE.

 

Applications:

  • Classifying whether a customer will purchase a product (yes/no).
  • Predicting whether a patient has a disease (0/1).

3.8 Predictions with Neural Network Models

Syllabus

Apply neural network models using an OOP to make predictions

  Learning Intention and Success Criteria

Learning Intention - Students will:

  • Apply neural network models using an object-oriented programming (OOP) approach to make predictions by building and training simple feedforward neural networks.

Success Criteria - Students can:

  • Explain the structure and functioning of a neural network.
  • Design a neural network model class using OOP principles.
  • Implement a basic neural network to perform prediction tasks and assess its performance.

  Content

Neural networks are powerful machine learning algorithms inspired by the structure of the human brain, designed to recognise complex patterns in data. By using an object-oriented programming (OOP) approach, we can create flexible and reusable neural network models to solve prediction tasks effectively.

Neural networks, particularly feedforward neural networks, consist of layers of interconnected nodes (neurons). These models are especially useful when dealing with large datasets with complex relationships that traditional regression models might struggle to capture.

 

Recall: Key Concepts of Neural Networks

  • Neurons and Layers:

    • A neural network consists of an input layer, one or more hidden layers, and an output layer. Each neuron in a layer receives inputs, applies weights and biases, and passes the result through an activation function to produce an output.

  • Feedforward Process:

    • In a feedforward neural network, data flows in one direction—from the input layer, through hidden layers, and to the output layer—without loops or cycles.

  • Activation Function:

    • The activation function introduces non-linearity to the model, enabling the network to learn and model complex relationships. Common activation functions include ReLU (Rectified Linear Unit) and sigmoid.

  • Backpropagation and Gradient Descent:

    • Neural networks are trained using backpropagation, a method that calculates the gradient of the loss function with respect to each weight in the network. This information is used to update the weights through gradient descent.

 

Implementing a Neural Network Using OOP

To build a neural network, we'll use OOP principles, creating a class-based design that encapsulates the functionality of a neural network and its training process. The structure of the class will allow for flexibility in modifying the network's architecture and training process.

 

Class Structure

A key benefit of OOP is the ability to encapsulate the functionality of the neural network into a single class. This class can manage the network's architecture (layers, neurons, weights, and biases), the forward and backward passes, and the training loop. Think of the class as the "blueprint" for how the neural network behaves.

Attributes:

In the neural network class, the attributes will store the essential information about the network:

  • Layers: Define the architecture of the neural network (e.g., input layer, hidden layers, output layer).
  • Weights and Biases: Initialise random weights and biases for the connections between neurons in different layers.
  • Learning Rate: Controls how much the model's weights are updated with respect to the error gradient during training.

Weight Initialisation:

Each connection between neurons in different layers gets a corresponding weight and bias.

Feedforward Process

The feedforward process computes the output of the neural network by passing the input data through each layer, applying weights, biases, and an activation function. This process is central to how neural networks make predictions.

How it Works:

  • Multiply the input by the weights, add the bias, and apply an activation function to introduce non-linearity. Popular activation functions include ReLU (Rectified Linear Unit) and sigmoid.

As neural networks involve multiple layers and complex transformations, the forward pass can be thought of like a journey: the input data gets progressively transformed through each layer until it reaches the output.

Activation Function

An activation function is essential in neural networks to introduce non-linearity, allowing the network to learn complex patterns. Without it, the model would simply perform linear transformations and wouldn't be able to solve complex tasks.

Popular choices:

  • ReLU: f(z)=max⁡(0,z)f(z) = \max(0, z)
  • Sigmoid: f(z)=11+e−zf(z) = \frac{1}{1 + e^{-z}}

Think of the activation function like a "filter" that lets the network make more nuanced decisions, much like how our brain processes subtle details. The activation function, by allowing non-linearity, gives the machine a form of intelligence to handle complex problems.

Backpropagation

Backpropagation is the heart of neural network training. It calculates the gradient of the loss function with respect to each weight using the chain rule of calculus, allowing the network to update its weights to minimise the prediction error.

How it Works:

  • During backpropagation, the network compares its output to the actual target (label) and computes the error (using a loss function like mean squared error for regression or cross-entropy for classification).
  • The network then "propagates" this error backward through the layers, calculating how much each weight contributed to the error.

 

 

The backward() method adjusts the weights and biases according to the gradients to minimise the error. Just as in life, where we learn from our mistakes, the network adjusts its internal parameters based on the errors it encounters.

Training

The train() method loops through the data, performs forward and backward passes, and updates the weights. This is where the network actually learns.

Training involves multiple iterations (epochs) over the dataset. With each iteration, the model’s predictions improve as the weights are refined.

3.9 Impact of Automation

Syllabus

Assess the impact of automation on the individual, society and the environment, including:

  • safety of workers
  • people with disability
  • the nature and skills required for employment
  • production efficiency, waste and the environment
  • the economy and distribution of wealth

  Learning Intention and Success Criteria

Learning Intention - Students will:

  • Assess the impact of automation on individuals, society, and the environment, particularly in terms of worker safety, inclusivity for people with disabilities, employment skills, production efficiency, and economic disparities.

Success Criteria - Students can:

  • Explain how automation affects worker safety and people with disabilities.
  • Evaluate how automation changes the nature of work and the skills required for employment.
  • Assess the effects of automation on production efficiency, waste, and environmental sustainability.
  • Analyse the impact of automation on the economy and the distribution of wealth.

  Content

Automation has revolutionised industries worldwide, driving significant changes in how we live and work. It involves the use of machines, robots, and artificial intelligence (AI) to perform tasks traditionally carried out by humans. This technological advancement has led to increased efficiency and productivity across sectors, but it has also raised concerns about its broader impacts on individuals, society, and the environment. Understanding these effects is crucial to navigate the benefits and challenges posed by automation.

 

Safety of Workers

Automation has transformed industries where hazardous conditions are a daily concern. By replacing humans in dangerous tasks, automation significantly reduces the risk of injury or fatality. Robotics and AI-driven systems are used in industries such as mining, manufacturing, and construction, where high risks were once unavoidable.

  • Case Study: Mining Industry
    In the mining sector, companies like Rio Tinto have integrated autonomous haulage systems (AHS) in Australian mines. These driverless trucks reduce the risks miners face from equipment accidents, toxic environments, and cave-ins. Workers are removed from the hazardous environment and instead operate the trucks remotely. This has led to a 50% reduction in safety incidents at some sites. However, it requires workers to have new skills in technology and system management.

  • Risks of Automation: While automation improves safety, it introduces new risks related to technical malfunctions. For example, in industries using robotic arms or automated machinery, a system failure could lead to accidents if proper safety protocols aren’t in place. Furthermore, automation’s increasing complexity requires skilled human oversight to maintain and operate these systems safely.

 

Read about the Rio Tinto Autonomous Train Collision Incident here

 

 

People with Disability

Automation offers significant opportunities to improve the lives and employment prospects of people with disabilities through assistive technologies. These systems range from robotic prosthetics to AI-powered software that assists with communication, mobility, and task performance.

  • Case Study: Assistive Robotics
    Ekso Bionics, a company that develops robotic exoskeletons, enables people with mobility impairments to walk again. This innovation allows individuals who previously would have been excluded from physically demanding jobs to participate in the workforce. Voice-activated systems like Amazon's Alexa or Apple's Siri allow people with disabilities to control workspaces with minimal physical interaction, boosting independence and productivity in office settings.

  • Challenges: Despite these benefits, the rise of automation also risks excluding people with disabilities in jobs heavily reliant on routine tasks. For instance, call centres or manufacturing roles, which often employ individuals with cognitive disabilities, are increasingly automated. This raises the concern that these workers could be displaced unless retraining initiatives are prioritised to help them transition to new roles.

 

 

Skills Required for Development

Automation is reshaping the job market by displacing roles that involve repetitive or predictable tasks, while creating demand for workers skilled in new technologies such as AI, data science, and robotics. As traditional jobs disappear, workers must adapt to new roles that emphasise creative problem-solving, collaboration with machines, and technical expertise.

  • Case Study: Manufacturing Industry
    Foxconn, a leading electronics manufacturer for companies like Apple, replaced over 60,000 workers with robots at one of its plants in China in 2016. The robots performed repetitive tasks more efficiently than humans, reducing labour costs and increasing production speed. However, the company also announced that workers would be retrained for more technical jobs, such as maintaining and overseeing the robots.

  • New Skill Demands: In Australia, the agriculture industry is experiencing a similar shift. Automated harvesting machines, such as robotic fruit pickers, are being introduced to address labour shortages and improve efficiency. Farmers now need to understand how to program, operate, and repair these machines, moving away from traditional manual labour to roles requiring technical and IT skills.

  • Lifelong Learning: The shift towards automation emphasises the need for continuous reskilling and upskilling. Workers must frequently update their skill sets to stay competitive in an automated job market. This has led to an increase in training programs focused on digital literacy, robotics, and data analytics, often supported by governments or private industries.

Efficiency, Waste and Environment

Automation has brought dramatic improvements to production efficiency, leading to cost savings and higher output while reducing waste. However, it also raises environmental concerns, particularly around energy use and the ecological impact of producing automated technologies.

  • Case Study: Tesla Gigafactory
    Tesla’s Gigafactory is an excellent example of how automation can optimise production while striving for sustainability. The factory uses a combination of robotics, AI, and renewable energy to produce electric vehicle batteries at an unprecedented scale. By integrating automated systems, Tesla has drastically reduced production time and costs. The factory also aims to be powered entirely by renewable energy, minimising its environmental impact. Additionally, automation in the factory has led to significant reductions in waste, as precision manufacturing ensures minimal material loss.

  • Environmental Concerns: Despite these advances, automation can contribute to increased energy consumption, particularly when automated systems are reliant on non-renewable energy. For example, the widespread use of data centres to support automation and AI processes leads to significant energy demands. According to the International Energy Agency (IEA), data centres consumed about 1% of the world’s electricity in 2021. Companies must invest in green technologies to ensure automation is environmentally sustainable.

  • Waste Reduction: Automation also reduces waste through precision agriculture. In Australian agriculture, automated irrigation systems and drones equipped with AI can monitor crop health and deliver water or pesticides precisely where needed, reducing water waste and the overuse of chemicals. This technology enhances both productivity and environmental sustainability.

Economy and Wealth

The economic impact of automation is profound, with both positive and negative consequences. While it drives economic growth and increases productivity, it also poses significant challenges to the fair distribution of wealth. Automation tends to disproportionately benefit capital owners and highly skilled workers, potentially widening the gap between the rich and poor.

  • Case Study: Amazon's Automated Warehouses
    Amazon uses automated systems in its warehouses to sort and ship products efficiently. Robots, such as Kiva Systems, transport goods within warehouses, reducing reliance on human labour. While this has allowed Amazon to scale rapidly, it has led to concerns over job losses and poor working conditions for the remaining human workers. Low-skilled workers are often at risk of displacement, while the wealth generated by these automated systems primarily benefits Amazon's shareholders and executives.

  • Wealth Inequality: Automation has a tendency to concentrate wealth in the hands of those who own the technology. AI and robotics companies, for example, see increased profits while workers, particularly in low-skilled jobs, are often displaced without a clear path to new employment. A 2020 study by MIT found that automation in the U.S. has contributed to wage stagnation for middle-class workers, while increasing profits for firms that deploy these technologies.

  • Policy Responses: In response, some governments are exploring policies like universal basic income (UBI) to mitigate the economic displacement caused by automation. This policy is being trialled in several countries, including Finland and Spain, as a means of providing financial security to those affected by job losses due to automation.

3.10 Human Behaviour Influences

Syllabus

Explore by implementation how patterns in human behaviour influence ML and AI software development, including:

  • psychological responses
  • patterns related to acute stress response
  • cultural protocols
  • belief systems

  Learning Intention and Success Criteria

Learning Intention - Students will:

  • Explore how patterns in human behaviour, including psychological responses, acute stress reactions, cultural protocols, and belief systems, influence the development of machine learning (ML) and artificial intelligence (AI) software.

Success Criteria - Students can:

  • Understand how psychological responses and stress-related patterns shape ML and AI system design.
  • Analyse how cultural and belief systems impact AI development.
  • Explore how these behavioural factors are incorporated into AI algorithms and systems through case studies and practical examples.

  Content

Human behaviour plays a significant role in shaping the development of machine learning (ML) and artificial intelligence (AI) systems. AI developers and researchers aim to create algorithms that not only analyse data but also interact effectively with users and reflect human behavioural patterns. Understanding how people respond psychologically, how stress affects decision-making, and how culture and belief systems influence behaviour is critical in designing AI systems that are ethical, user-friendly, and contextually appropriate.

 

Psychological Responses

Humans react emotionally and psychologically to technology, and these responses shape how AI systems are designed to interact with users. Factors like trust, fear, and cognitive biases are crucial considerations when building AI systems that users rely on.

Key Concepts:

  • Trust and User Adoption:

    • Users are more likely to adopt AI systems if they trust the recommendations or decisions made by the system. Trust is built through transparency (e.g., explainable AI) and reliability.

  • Fear and Resistance:

    • Psychological fear of AI, often referred to as "automation anxiety", can affect how users interact with AI systems. Developers need to create systems that feel intuitive and friendly to reduce resistance.

  • Cognitive Bias:

    • AI systems must be designed to account for human cognitive biases. For example, users may experience confirmation bias, where they favor AI outputs that confirm their pre-existing beliefs.

Example in Implementation:

In healthcare AI, systems are designed to provide transparency in their decision-making processes to build trust with medical professionals. When suggesting a diagnosis, AI systems often provide explanations for their recommendations, easing concerns that doctors may have about handing over too much control to a machine.

 

Acute Stress Response

Acute stress can significantly influence how humans interact with AI systems, especially in high-pressure environments such as emergency services or military operations. People under stress may have impaired decision-making abilities, rely more on heuristics, and exhibit fight-or-flight responses, which must be considered when designing AI that operates in these contexts.

Key Concepts:

  • Fight-or-Flight Response:
    • In stressful situations, users may need quick, simple solutions rather than complex, data-heavy recommendations. AI systems should be designed to offer straightforward, easily digestible information during critical moments.
  • Cognitive Load:
    • High-stress environments increase cognitive load—the amount of mental effort required to process information. AI systems must minimize the cognitive load on users by providing clear and concise outputs, avoiding overwhelming amounts of data.

Example in Implementation:

In AI-driven emergency response systems, like those used in disaster management, stress patterns are considered by presenting critical information in a simplified format. Visual alerts, concise instructions, and real-time updates are prioritised to help first responders make quick, informed decisions under pressure.

Cultural Protocols

Cultural diversity influences how people perceive and interact with AI systems. Developers need to consider cultural norms and practices when designing AI systems for different regions or communities to ensure the technology is respectful, acceptable, and useful across various cultural contexts.

Key Concepts:

  • Cultural Sensitivity:

    • AI systems should be tailored to align with the cultural practices and expectations of the target users. This can include language preferences, gender roles, or traditional values that differ across cultures.

  • Localisation:

    • Localisation of AI refers to adapting the system to meet the specific cultural, linguistic, and social needs of different populations. This includes language translation, cultural references, and contextually appropriate interactions.

Example in Implementation:

Voice assistants like Amazon Alexa or Google Assistant often undergo significant cultural adaptation when being deployed in different countries. For instance, these systems are programmed to recognise local dialects, respect local customs (e.g., addressing people more formally in certain cultures), and follow region-specific social norms.

 

Belief Systems

Belief systems, including religion, moral philosophies, and ethical frameworks, shape how AI systems are perceived and accepted in various societies. Developers must account for these belief systems to avoid ethical conflicts and ensure that AI systems operate within acceptable moral boundaries.

Key Concepts:

  • Ethical AI:

    • Developers must ensure that AI systems do not conflict with the ethical and moral standards of their users. For instance, certain communities may oppose AI in areas like surveillance or genetic modification based on religious beliefs.

  • Bias and Fairness:

    • AI systems must be designed to avoid bias, especially in culturally diverse societies. Developers should incorporate fairness and inclusivity into AI algorithms, ensuring that systems do not discriminate based on gender, race, religion, or other belief systems.

Example in Implementation:

In facial recognition technology, ethical AI development considers potential biases against specific racial or ethnic groups. Developers implement fairness techniques to ensure that the system works equally well across different demographics, reducing the risk of unfair treatment.

3.11 Investigating Bias

Syllabus

Investigate the effect of human and dataset source bias in the development of ML and AI solutions

  Learning Intention and Success Criteria

Learning Intention - Students will:

  • Understand how human and dataset biases can impact the development and outcomes of machine learning (ML) and artificial intelligence (AI) models.

Success Criteria - Students can:

  • Explain the role of human bias in AI development.
  • Describe how biases in datasets are introduced and propagated in ML models.
  • Evaluate the potential consequences of biases on AI decision-making.
  • Suggest methods to mitigate bias in AI systems.

  Content

Bias in machine learning and artificial intelligence arises when the models, data, or decisions made by developers unintentionally favour certain outcomes, groups, or perspectives over others. This can occur due to two primary factors:

  1. Human Bias – The biases held by the developers, data scientists, or organisations.
  2. Dataset Source Bias – The biases present within the data that is used to train AI models.

These biases can have profound effects on the fairness, accuracy, and inclusivity of AI systems, leading to ethical concerns and practical challenges in real-world applications.

 

Human Bias

Human bias refers to the implicit and explicit preferences, beliefs, or assumptions that developers may hold, which can influence the design and decision-making processes involved in creating AI systems. Examples include:

  • Feature Selection: The choice of variables or features for a model can reflect the developer's priorities or preconceived notions about what is important. For instance, if socio-economic status is prioritised as a feature in predictive models for employment, the model may perpetuate existing inequalities.
  • Algorithm Design: Developers might unintentionally favour certain algorithmic structures or processes that reflect their own experiences or goals, even if those structures introduce bias.
  • Labelling Bias: During the creation of datasets, humans often label data (e.g., tagging images or categorising information). Their labels may reflect personal biases, reinforcing stereotypes or errors.

 

Dataset Source Bias

 Dataset bias occurs when the data used to train machine learning models is not representative of the broader population or task. There are several ways dataset bias can be introduced:

  • Historical Bias: This occurs when the dataset reflects past inequalities or discriminations. For instance, if a hiring algorithm is trained on historical data from an industry with low gender diversity, it may learn to favour male candidates over female candidates.
  • Sampling Bias: If certain groups are overrepresented or under-represented in the dataset, the model will generalise poorly to the under-represented groups. For example, medical AI systems trained on data from one demographic may fail to accurately diagnose or recommend treatments for another.
  • Label Bias: The way data is classified or labelled can introduce biases, particularly in cases where human judgement is required, such as labelling hate speech or offensive content in social media posts. Label bias can reflect cultural or individual bias, making certain words or behaviours disproportionately flagged as problematic.

 

 

Consequences of Bias in AI Systems

The effects of human and dataset bias in AI systems can be significant, leading to:

  • Discrimination: Biased AI systems may discriminate against certain groups based on race, gender, or socio-economic status. For example, biased recruitment algorithms can perpetuate gender inequality in hiring.
  • Reduced Trust: Users and society may lose trust in AI systems if they consistently produce unfair or biased outcomes.
  • Poor Decision-Making: Bias in models can lead to inaccurate or inappropriate decisions. For example, a biased healthcare algorithm could result in misdiagnoses for under-represented populations.
  • Legal and Ethical Implications: Many countries have anti-discrimination laws, and biased AI systems could lead to legal challenges. Furthermore, there are growing concerns about the ethical responsibility of organisations deploying AI systems.

Mitigating Bias in AI Development

Several strategies can be employed to reduce bias in AI models:

  1. Diverse Teams: Building teams with diverse perspectives can help mitigate bias by ensuring that different viewpoints are considered during AI development.
  2. Bias Audits and Testing: Conducting audits and testing models for bias across different demographic groups can help identify and correct biased behaviour.
  3. Inclusive Datasets: Curating and using datasets that are representative of the entire population can help prevent dataset bias. This might include collecting additional data for under-represented groups.
  4. Algorithmic Fairness: Using fairness-aware algorithms that aim to equalise outcomes for different groups can be an effective mitigation strategy.
  5. Transparency and Accountability: Making AI models and decisions more transparent, and holding developers accountable for biased outcomes, is essential for ensuring fair AI development.

Example: Mitigating Bias in Hiring Algorithms

To reduce gender bias in hiring algorithms, companies have implemented strategies like anonymising candidate resumes (removing names and genders) and training models on more inclusive datasets that do not reflect historical gender biases.
