Syllabus
Apply skills in computational thinking and programming to develop a software solution, including:
- converting an algorithm into code
- using control structures
- using data structures
- using standard modules
- creating relevant subprograms that incorporate parameter passing

  Learning Intention and Success Criteria

Learning Intention - Students will:

  • Apply their computational thinking and programming skills to develop a software solution that involves converting an algorithm into code, utilising control structures, incorporating standard modules, and creating subprograms involving parameter passing.

Success Criteria - Students can:

  • Successfully convert a given algorithm into functional code.
  • Demonstrate the effective use of control structures, such as loops and conditional statements.
  • Implement appropriate data structures for storing and manipulating data, such as lists, dictionaries, or tuples.
  • Integrate standard modules and libraries to enhance the functionality of the software solution.
  • Create and utilise subprograms (functions or methods) that effectively incorporate parameter passing to achieve modular and reusable code.
  • Test and debug the software solution to ensure it meets the desired requirements and functions as intended.

Login Module

Here is an example of a standard login module. This can be used for future projects where login screen is required.

Pseudocode Python 
BEGIN Login(Username, Password) 
    Let Match = FALSE
    WHILE Match = FALSE
        GET EntUsername
        GET EntPassword
        IF Username = EntUsername AND Password = EntPassword THEN
            LET Match = TRUE
            Display "Login Sucessful"
        ELSE
            Display "Incorrect login credentials"
        ENDIF
   ENDWHILE       
END Login
 
def login(username, password): 
    match = False 
    while not match: 
        ent_username = input("Enter Username: ") 
        ent_password = input("Enter Password: ") 
        if username == ent_username and password == ent_password: 
            match = True 
            print("Login Successful") 
        else: 
            print("Incorrect login credentials") 


username = "example_user" 
password = "example_password"

Linear Array Iteration Module

Here is an example of an interaction through a standard array. Linear iteration is very common for coding fundamentals, and the skills are also transferable to string manipulation. 

 

Pseudocode Python 
BEGIN LinearArray 
    Get Array()
    LET i = 0
    WHILE i < number of elements in the array
        LET Array(i) = i
        LET i = i +1
        Display "Array at position "+i+" = "+i
    ENDWHILE
END LinearArray
 

def linear_array():
  array = [] #Empty array
  num_elements = 10 #Example number of elements
  i=0
  while i < num_elements:
    array.append(i)
    print("Array at position",i,"=",array[i])
    i+=1

Binary Search

Binary Search

The task is to determine whether or not a particular data value (the target) is present in a set of data. If the target is found the position of its first occurrence is reported and the search ends.

    Note that the binary search will only work on sorted data.

Binary search divides the data set into two parts and determines in which part the element is likely to be found. The other part of the data is discarded, and the retained part is divided into two parts. The process is continued until the value is found or there are no more elements in the data set to be checked. If a match is found then the position of the match is reported otherwise a message is written telling the user that the target is not present in the data.

At each division, there are three possibilities for the target (if it exists in the data set):

  1. the target lies at the division point
  2. the target lies to the left of the division point
  3. the target lies to the right of the division point

Pseudocode Python 
BEGIN BinarySearch
    LET Lower = 1
    LET Upper = number of elements in the array
    LET FoundIt = false
    GET RequiredName
    REPEAT
        LET Middle = (Upper + Lower) / 2
        LET Middle = integer part of Middle
        IF RequiredName = Name (Middle) THEN
            LET FoundIt = true
            LET PositionFound = Middle
        ELSE
            IF RequiredName < Name (Middle) THEN
                LET Upper = Middle – 1
            ELSE
                LET Lower = Middle + 1
            ENDIF
        ENDIF
    UNTIL FoundIt OR Lower > Upper
    IF FoundIt THEN
        Display “Required name found at ” PositionFound
    ELSE
        Display “Required name ” RequiredName “ not found.”
    ENDIF
END BinarySearch
 
def binary_search(names, required_name): 
    lower = 0 
    upper = len(names) - 1 
    found_it = False 

    while not found_it and lower <= upper: 
        middle = (upper + lower) // 2 
        if required_name == names[middle]: 
            found_it = True 
            position_found = middle 
        else: 
            if required_name < names[middle]: 
                upper = middle - 1 
            else: lower = middle + 1 

    if found_it: 
        print(f"Required name found at position {position_found}") 
    else: 
        print(f"Required name {required_name} not found.")

    Note that the Pseudocode uses a post-test loop while the Python uses a pre-test loop as Python does not have a built-in post-test loop.
