# Software Engineering podcast: transcripts

166 episodes from the HSC Podcast app: **137 syllabus episodes** and **29 case studies**, about 505,136 words of scripts.

Each folder has `script.md` (the transcript), usually `supplementary.md` (notes) and `quiz.json` (questions).
Syllabus episodes are named by syllabus point (e.g. `SSA-16-02` = Secure Software Architecture, content point 16).

To listen with audio, build the app yourself from **https://github.com/freddygaffey/hsc-podcast** (see its README).

Also here: [`GLOSSARY.md`](GLOSSARY.md).
