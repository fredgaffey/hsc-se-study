Unit2 2.11 Code Libraries

Syllabus

Explore the types and significance of code libraries for front-end web development, including:

  • frameworks that control complex web applications
  • template engines
  • predesigned CSS classes

  Learning Intention and Success Criteria

Learning Intention - Students will:

  • Understand the types and importance of code libraries in front-end web development.

Success Criteria - Students can:

  • Identify different libraries for frameworks, template engines, and CSS classes
  • Describe the use of different libraries in web development
  • Discuss the significance of code libraries for front-end web development

  Content

 

Web Frameworks

In the early 2000s, making web pages interactive required manually writing JavaScript for animations, form validation, and AJAX requests. Developers had to handle DOM manipulation with raw JavaScript or jQuery, which made complex applications difficult to maintain!

As web applications grew in complexity, JavaScript frameworks like Angular (2010) and React (2013) emerged. These frameworks introduced component-based architecture, state management, and reusable functions, reducing the need for manual scripting.

  • JavaScript Frameworks: Reusable UI components, state management, and hooks to build web applications. 
    e.g. React.js, Vue.js, Svelete

  • Full-Stack Frontend: Includes UI rendering, but extends this by including file-based routing and server-side rendering.
    e.g. Next.js, Angular

  • Static Site Generators: Generates pre-rendered HTML pages for fasting loading and optimisation
    e.g. Gatsby, Hugo, Flask

Significance: How Web Frameworks Changed Development

  • Prebuilt Functions & Components:
    Instead of writing custom JS for everything, developers can now use pre-built libraries and community-driven components.
  • Faster Development:
    Features like data binding (Angular) and virtual DOM (React) automate updates, reducing manual DOM manipulation.
  • Scalability & Maintainability:
    Component-based design ensures that code is modular and easier to maintain in large applications.
  • Huge Community Support:
    Open-source contributions allow developers to reuse and extend functionality, speeding up development.

 

Template Engines

Initially, websites were purely static, with each page being a separate HTML file. If a site had 100 pages, developers had to manually update each file, making maintenance difficult!

To solve redundancy, template engines (e.g., PHP, EJS, Jinja2) emerged in the early 2000s, allowing developers to reuse HTML components (headers, footers, nav bars) across pages, avoiding duplication of HTML and scale projects without the files growing too large. Languages like Python (Flask, Django) and Node.js (Express + EJS/Pug) allowed pages to be rendered dynamically on each request.

  • Server-Side Template Engines: Server-side rendering (SSR) generates HTML on the server before sending it to the browser for display. Hence, the server manages both the front end and back end. 
    e.g. Jinja2, EJS

  • Client-Side Template Engines: Libraries like Mustache and Handlebars can also be used on the client side, allowing developers to dynamically generate and update HTML without server interaction.

Significance: Template Engines Changed Development

  • Reusable Components:
    Instead of duplicating HTML, developers can use partials and includes to manage layouts efficiently.
  • Separation of Concerns:
    HTML is kept clean and structured, while logic and styling are managed separately.
  • Scalability & Maintainability:
    Modular templates prevent large, unmanageable files, making updates easier.
  • Server-Side Rendering (SSR) Support:
    Engines like Jinja2 (Flask) and EJS (Node.js) enable faster initial page loads and better SEO.

 

Predesigned CSS Classes

Predesigned CSS libraries offer sets of pre-styled components and utility classes that can be used to quickly build responsive and visually appealing user interfaces.

  • UI Frameworks: Libraries like Bootstrap, Foundation, and Bulma provide a comprehensive set of components (buttons, forms, modals, etc.) that are pre-styled and responsive, making it easier to create consistent UIs.
  • Utility-First CSS Frameworks: Frameworks like Tailwind CSS focus on providing utility classes for common styling needs (e.g., margins, padding, colours), allowing for more customised designs without writing extensive CSS.

Signifance: Impact of CSS Classes

  • Speeds Up Development: Using predesigned CSS classes allows developers to quickly style elements without starting from scratch, saving time and effort.
  • Ensures Consistent Design: Predesigned classes follow a consistent design language, helping to maintain visual consistency throughout the application.
  • Responsive Design: Most modern CSS libraries are built with responsive design in mind, making it easier to create layouts that work across different screen sizes and devices.
  • Customisability: While these libraries provide pre-styled components, they are often flexible enough to be customised, allowing developers to adapt the design to specific project requirements.
