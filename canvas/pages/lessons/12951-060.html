  Content

 

What is SQL?

SQL (Structured Query Language) is a domain-specific language designed for managing and manipulating relational databases. It is the standard language used to interact with databases that store data in tables (rows and columns) and is integral to modern web-based applications. SQL allows users to perform various operations on data, including querying (retrieving data), updating, deleting, and inserting new records, as well as managing database structure and access control.

 

Key Characteristics of SQL

SQL’s key features are essential for efficiently managing and interacting with relational databases. These include the ability to retrieve data with SELECT, filter results using WHERE, and sort or group data using ORDER BY and GROUP BY. SQL also supports aggregating data with functions like COUNT() and SUM(), and allows combining data from multiple tables through joins. These features are crucial for performing detailed queries and analyses on structured datasets.

 

Declarative Language

SQL is considered a declarative language, meaning that instead of explicitly coding how the data should be retrieved or manipulated, you declare what you want, and the database system figures out the optimal way to do it. For example, you specify which data you want (SELECT statement), but you don’t control the internal processes that the database engine uses to retrieve it.

Relational Databases

SQL is used primarily with relational databases, which organise data into tables. Each table contains rows and columns, where rows represent records (individual data entries) and columns represent fields (specific data attributes like name, age, or salary). Relationships between different tables can be established via key fields, enabling complex queries that span multiple tables.

Standardised Language

SQL is governed by various standards, with the most well-known being ANSI SQL. Although different database management systems (DBMS) like MySQL, PostgreSQL, Oracle, and Microsoft SQL Server may have slight variations, they all generally adhere to the SQL standard. This standardisation makes SQL a widely transferable and universal language in the database domain.

SQL Operations

SQL allows for a wide range of operations, from querying data to modifying the structure of the database. Some key operations include:

  • Data Retrieval: Using SELECT statements to query data from one or more tables.
  • Data Manipulation: Inserting, updating, or deleting records with INSERT, UPDATE, and DELETE commands.
  • Data Definition: Creating and modifying tables, indexes, and relationships using commands like CREATE TABLE and ALTER TABLE.
  • Data Control: Managing access to the database with GRANT and REVOKE to control user permissions.

 

Constructing SQL Commands

Constructing SQL statements involves creating structured queries that perform specific actions on a database. A typical query begins with the SELECT statement to define which fields to retrieve. Data is pulled from the relevant table(s) specified in the FROM clause, and you can refine the results using the WHERE clause to filter the dataset based on specific conditions. The GROUP BY clause can be used to aggregate data, while ORDER BY helps you organize the results in a specific sequence. By combining these elements, you can construct complex queries to extract and analyze the data you need from a relational database.

 

SELECT

In SQL, the SELECT statement is used to retrieve specific data from a table. The fields you want to display must be explicitly defined.

 

Basic Syntax:

SELECT field1, field2, field3
FROM table_name;

 

Example:

SELECT first_name, last_name 
FROM employees;

 

FROM

For the purposes of this course, we use a simplified approach to joining tables. Instead of explicitly using JOIN clauses, you can list multiple tables in the FROM clause, and SQL will automatically link the tables based on common fields, provided those fields are correctly referenced in the WHERE clause.

 

HSC SQL Example:

SELECT employees.first_name, departments.department_name
FROM employees, departments
WHERE employees.department_id = departments.department_id;

 

In this version:

  • You simply list the tables (e.g., employees, departments) in the FROM clause.
  • Then, specify the relationship between the tables using a condition in the WHERE clause (e.g., employees.department_id = departments.department_id).

This method simplifies the syntax for educational purposes, but the logic behind how the tables are joined remains the same.

 

SQL JOIN Keyword

In real-world SQL, joins are typically done using explicit JOIN clauses, such as INNER JOIN, LEFT JOIN, and RIGHT JOIN, which provide more control over how the data is combined. These joins require a more formal structure but are commonly used in professional database management.

Standard SQL Example (INNER JOIN):

SELECT employees.first_name, departments.department_name
FROM employees
INNER JOIN departments
ON employees.department_id = departments.department_id;

 

WHERE

The WHERE clause is used to specify conditions that must be met for records to be included in the results. This is critical for narrowing down large datasets and focusing on the information you need.

 

Basic Filtering with WHERE:

SELECT field1, field2
FROM table_name
WHERE field1 = 'value';

 

Example: Retrieve all employees who work in the "Sales" department:

SELECT first_name, last_name
FROM employees
WHERE department = 'Sales';

 

Relational Operators Available in SQL:

  • =: Equals
  • != or <>: Not equals
  • >: Greater than
  • >=: Greater than or equal to
  • <: Less than
  • <=: Less than or equal to

Logical Operators:

  • AND: Combines conditions, both must be true.
  • OR: At least one condition must be true.
  • NOT: Negates the condition.

Example with Logical Operators:

  • Find employees in the "Sales" department who earn more than 50,000:
SELECT first_name, last_name
FROM employees
WHERE department = 'Sales' AND salary > 50000;

 

ORDER BY

The ORDER BY clause in SQL is used to sort the results of a query based on one or more columns. By default, SQL sorts the data in ascending order (A–Z or 0–9), but you can also specify descending order (Z–A or 9–0) if needed. This is particularly useful when you want to organise your query results in a specific way, such as alphabetically, by date, or numerically.

 

Syntax for ORDER BY:

SELECT field1, field2 
FROM table_name 
ORDER BY field1 [ASC|DESC]; 

 

Sort Results in Ascending Order 

SELECT first_name, last_name
FROM employees
ORDER BY last_name ASC;

This query retrieves the first and last names of employees and orders them alphabetically by last_name.

 

Sort Results in Descending Order:

SELECT first_name, last_name, salary 
FROM employees 
ORDER BY salary DESC;

This query retrieves employee names and their salaries, ordering the results from the highest salary to the lowest using DESC.

 

GROUP BY

The GROUP BY clause groups rows that have the same values in specified columns. This is typically used in conjunction with aggregate functions like SUM(), COUNT(), AVG(), MAX(), and MIN().

 

Basic Syntax:

SELECT field1, COUNT(*)
FROM table_name
GROUP BY field1;

 

Example:

SELECT department, COUNT(*)
FROM employees
GROUP BY department;

 

Using the GROUP BY Clause with Aggregate Functions

When you need to summarise data, such as calculating totals or averages, you will use aggregate functions alongside GROUP BY.

Available Aggregate Functions:

  • SUM(field): Returns the total sum of values in a field.
  • AVG(field): Returns the average of values in a field.
  • COUNT(field): Counts the number of rows or occurrences.
  • MAX(field): Returns the highest value in a field.
  • MIN(field): Returns the lowest value in a field.

Example:

  • Calculate the total sales per department:
SELECT department, SUM(sales)
FROM employees
GROUP BY department;
