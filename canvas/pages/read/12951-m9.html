3.1 Machine Learning and Automation

Syllabus

Investigate how machine learning (ML) supports automation through the use of DevOps, robotic process automation (RPA) and business process automation (BPA)

  Learning Intention and Success Criteria

Learning Intention - Students will:

  • Explore the role of machine learning (ML) in automation, particularly in relation to DevOps, Robotic Process Automation (RPA), and Business Process Automation (BPA).

Success Criteria - Students can:

  • Define and explain Machine Learning.
  • Define DevOps, RPA, and BPA, and describe their purposes.
  • Describe how Machine Learning is integrated into each form of automation.
  • Provide practical examples of ML in DevOps, RPA, and BPA.

  Content

As technology becomes more important in our everyday lives, automation helps make tasks faster and easier. Machine Learning (ML) is a type of artificial intelligence that allows computers to learn from data and make decisions without constant human help. 

 

What is Machine Learning (ML)?

Machine Learning (ML) is a subset of artificial intelligence (AI) that allows computer systems to learn from and make decisions based on data without explicit programming. ML algorithms use patterns and inference from data to improve their performance over time. These algorithms can process large datasets, detect trends, and make decisions with minimal human intervention.

Key Characteristics:

  • Learning from data: ML systems improve with more data and experience.
  • Prediction and decision-making: ML helps predict future trends and outcomes based on historical data.
  • Automation: It enables machines to automate processes by identifying patterns that a human may not detect easily.

 

DevOps

DevOps is a set of practices that combines software development (Dev) and IT operations (Ops). Its goal is to shorten the system development life cycle and deliver high-quality software more efficiently. DevOps promotes continuous integration and continuous delivery (CI/CD), automation of infrastructure, and collaboration across teams.

 

Predictive Analytics in CI/CD Pipelines

In DevOps, the CI/CD pipeline automates the process of building, testing, and deploying code. This allows development teams to deliver features and fixes rapidly. However, managing CI/CD pipelines involves frequent monitoring and adjustments, especially when builds fail or deployments break down. Machine learning can automate this monitoring and introduce predictive analytics that anticipates issues before they occur.

 

How ML Supports CI/CD:

Machine learning models can analyse historical build data—such as failure patterns, commit frequency, and the types of changes made—to predict which builds are likely to fail or which changes may introduce bugs. This predictive capability helps DevOps teams by:

  • Failure Prediction: ML algorithms can assess new code changes against past failures, identifying patterns where similar modifications have led to problems. The system can flag potentially risky code early, suggesting additional tests or fixes before the pipeline proceeds to production.
  • Build Optimisation: DevOps aims to optimise the CI/CD process to ensure faster and more reliable releases. ML can identify bottlenecks, such as slow-running tests or frequently failing deployments, and recommend solutions, such as prioritising high-risk test cases or automatically rerouting jobs to alternative environments if a failure is predicted.

Example:

A global company like Spotify could use ML to analyse its CI/CD pipeline performance. ML models would detect patterns that lead to build failures, allowing engineers to address these proactively. For instance, if a specific module tends to cause issues after a large update, ML can recommend running more rigorous tests on this module, or even rerouting jobs to a healthier pipeline node.

Intelligent Resource Management

Managing infrastructure efficiently is crucial in DevOps, especially when systems must handle varying loads while avoiding both over-provisioning (wasting resources) and under-provisioning (leading to system crashes). In traditional DevOps, infrastructure scaling is based on pre-defined rules and monitoring data, but this approach can struggle with unexpected traffic surges or complex cloud environments.

 

How ML Enhances Resource Management:

Machine learning enables dynamic, predictive resource management by analysing patterns in system usage and predicting future demands. This allows DevOps teams to move beyond reactive scaling and instead implement intelligent, proactive autoscaling. ML models can:

  • Predict Traffic Spikes: Based on historical data, machine learning can forecast when traffic spikes might occur—such as during a product launch or sale. By predicting these spikes, ML can automatically scale infrastructure up or down to ensure enough resources are available without over-allocating.
  • Optimise Cost Efficiency: ML can identify opportunities to save costs by automatically selecting the most cost-effective instance types or cloud regions. It can also ensure that resources are de-allocated when they’re no longer needed, reducing wastage.

Example:

Netflix, a company that operates at a massive scale, can use ML-driven autoscaling in its cloud infrastructure. By analysing user activity data and predicting peak times (like evenings when more users are likely to stream content), Netflix can ensure that its infrastructure can handle the load without over-provisioning. This intelligent scaling supports DevOps efforts by minimising downtime and improving cost efficiency.

Automated Incident Management

In DevOps, handling incidents—such as failures in deployment, downtime, or performance degradation—requires quick identification of the root cause. Traditional incident management involves manual log analysis and cross-referencing of metrics, which can be time-consuming, especially in complex, large-scale environments.

 

How ML Improves Incident Management:

Machine learning automates incident detection and root cause analysis by continuously monitoring system logs, metrics, and traces, and identifying patterns that indicate potential problems. ML can:

  • Predict Failures: Based on historical data, ML models can detect early warning signs that a system or service may be about to fail, allowing teams to address the issue before it escalates. This reduces downtime and prevents service outages.
  • Log Analysis and Correlation: ML can process and analyse vast amounts of log data across multiple services and systems, automatically correlating events and narrowing down the root cause of an issue. Instead of engineers spending hours sifting through logs, the ML system provides insights into the most likely causes, speeding up incident resolution.

Example:

In a cloud environment like AWS, DevOps teams might use ML-driven tools like Amazon’s CloudWatch to automatically analyse logs and performance data. If an application starts to slow down or experience high error rates, ML models can correlate this to recent code deployments or configuration changes. This allows the team to pinpoint the cause and apply fixes faster, thus supporting the DevOps goal of minimising downtime.

 

 

What is MLOps?

MLOps is the automated process of designing, training and deploying machine learning models. It borrows many of the same principles and practices used in DevOps, bringing together the teams involved in developing machine learning models and the operational teams involved in deploying and supporting the models in production.

 

Design:

  • defining the business problem to be solved
  • refactoring the business problem into a machine learning problem
  • defining success metrics
  • researching available data.

Model development:

  • data wrangling
  • feature engineering
  • model training
  • model testing and validation.

Operations:

  • model deployment
  • supporting operations/use
  • monitoring model performance.

 

Robotic Process Automation (RPA)

Robotic process automation (RPA) uses software robots or "bots" to automate repetitive, rule-based tasks traditionally performed by humans. These tasks include activities like data entry, report generation, and interacting with multiple software systems. RPA mimics human actions by interacting with user interfaces, handling tasks that follow structured logic and defined workflows.

While RPA is highly effective for automating simple, repetitive tasks, it has limitations when it comes to handling complex, unstructured data or tasks that require cognitive decision-making. This is where machine learning (ML) significantly enhances RPA. By integrating ML, RPA systems can move beyond rule-based automation and tackle more sophisticated processes, including those that require learning from past data, making predictions, or adapting to new information.

 

Handling Unstructured Data

Traditional RPA excels at automating tasks with structured data, like extracting information from spreadsheets or entering data into form fields. However, many business processes involve unstructured data, such as emails, PDFs, images, and scanned documents, which are harder for rule-based RPA bots to interpret. Machine learning enables RPA to process and extract insights from these types of data.

 

How ML Supports Unstructured Data Processing:

Machine learning models, particularly those involving natural language processing (NLP) and computer vision, allow RPA bots to interpret and process unstructured data:

  • Text Recognition: Using optical character recognition (OCR) combined with ML, RPA bots can read and extract relevant information from scanned documents, images, or handwritten notes. This allows automation of tasks like processing invoices, where data is often presented in non-standard formats.
  • Natural Language Understanding (NLU): ML models can analyse and understand human language, enabling RPA bots to automate processes that involve reading and interpreting emails, customer feedback, or documents. This allows bots to respond to inquiries, route requests, or generate reports from unstructured text data.

Example:

In the banking sector, automating loan application processing often involves reading customer-submitted documents like bank statements and identification forms. RPA bots equipped with ML-powered OCR can extract key information from these documents, such as names, addresses, and financial details, even if the formats vary. ML models ensure that the bot learns to improve its accuracy over time by recognising common patterns and reducing errors in data extraction.

 

Intelligent Decision-Making

Traditional RPA follows pre-defined workflows, where bots execute tasks based on if-then rules. While effective for simple tasks, this rule-based approach lacks flexibility when dealing with more dynamic, decision-based processes that require analysing data and choosing actions based on context. Machine learning introduces intelligence into RPA by enabling bots to make decisions based on historical data and learned patterns.

 

How ML Enables Intelligent RPA:

ML models can analyse large datasets to identify trends and predict outcomes, enabling RPA to:

  • Predictive Decision-Making: Bots can use ML to predict outcomes based on past data. For example, in customer service, ML can predict the best resolution path based on previous interactions, allowing the bot to automatically choose the best response or action.
  • Adaptive Workflows: Machine learning enables RPA bots to adapt to changes in workflows by learning from past experiences. If a task has multiple possible outcomes, the bot can choose the best option based on previous success rates, making the process more efficient and accurate over time.

Example:

In insurance claims processing, ML-enhanced RPA can automatically review claims and predict whether a claim is likely to be approved based on past data. The bot analyses historical claims data, learns which claims tend to be successful, and applies that knowledge to new claims. This predictive capability streamlines decision-making and reduces the need for manual review, speeding up the entire process.

 

By integrating ML into RPA, organisations can significantly expand the scope and efficiency of their automation efforts. Key benefits include:

  • Improved Accuracy: Machine learning allows RPA bots to continually improve through experience, reducing errors and improving performance over time.
  • Enhanced Flexibility: Unlike rule-based RPA, ML-enabled bots can handle a wide range of tasks, including those involving unstructured data or complex decision-making.
  • Scalability: With the ability to learn and adapt, ML-empowered RPA can easily scale to handle larger workloads or more complex tasks without needing constant reprogramming.

 

 

Business Process Automation (BPA)

Business Process Automation (BPA) is the use of technology to automate complex business processes, aiming to increase efficiency, reduce human error, and improve overall productivity. BPA handles tasks that typically involve multiple systems, departments, or workflows and helps streamline operations by automating end-to-end processes.

Unlike simple task automation, BPA addresses larger, cross-functional workflows, such as onboarding employees, managing customer service requests, or automating financial operations. Traditionally, BPA follows predefined rules and processes but struggles to handle tasks that involve complex decision-making or unstructured data.

 

Automating Decision-Making

Traditional BPA systems follow rigid rules to automate business processes. However, many business operations involve decision-making that can’t be fully captured by predefined logic. Machine learning can analyse historical data and current context to automate decisions, enhancing BPA’s capabilities by making workflows more dynamic and responsive.

 

How ML Supports Decision-Making in BPA:

  • Pattern Recognition and Decision Support: ML models analyse large volumes of historical data and use these insights to identify patterns that guide decision-making. For example, in customer service processes, ML can automatically route inquiries to the right department based on past ticket handling efficiency.
  • Predictive Analytics: ML can predict the outcome of different business processes, enabling BPA systems to make smarter decisions in real-time. For instance, when processing loan applications or approving insurance claims, ML models can predict approval likelihood based on applicant data, reducing the need for manual reviews.

Example:

In supply chain management, machine learning enhances BPA by predicting inventory levels based on past sales, current trends, and external factors like seasonality. Instead of manually adjusting orders or running reports, BPA systems equipped with ML automatically place orders or make recommendations to optimise stock levels and avoid shortages or overstocking.

Handling Unstructured Data in Business Workflows

One of the limitations of traditional BPA is its reliance on structured data—data that fits neatly into tables, forms, or databases. However, a significant portion of business operations involves unstructured data, such as emails, reports, contracts, and customer feedback. Machine learning, especially through natural language processing (NLP) and computer vision, enables BPA to automate tasks that involve interpreting and processing unstructured data.

 

How ML Helps Process Unstructured Data in BPA:

  • Text and Document Processing: ML models, particularly those involving NLP, allow BPA systems to process unstructured text. For example, ML-enhanced BPA can automatically classify and extract information from emails, contracts, or reports and integrate it into workflows.
  • Document Classification and Information Extraction: ML can be used to classify incoming documents or identify relevant pieces of information. For instance, when onboarding a new client, BPA systems can scan documents, extract important details (like contract terms or customer details), and automatically populate fields in relevant systems.

Example:

In human resources (HR) processes, ML-enhanced BPA can automatically handle unstructured resumes submitted by job applicants. Machine learning models can scan resumes, extract key information such as work history and qualifications, and rank candidates based on their likelihood to be a good fit for a particular role. This significantly reduces the manual effort involved in resume screening and allows HR teams to focus on more strategic tasks.

 

Integrating machine learning into BPA leads to several benefits, including:

  • Enhanced Efficiency: ML reduces manual intervention by automating decision-making and tasks involving unstructured data, resulting in faster workflows.
  • Improved Accuracy: By learning from past data, ML models improve over time, increasing the accuracy of predictions and reducing errors in business processes.
  • Scalability: With ML, BPA systems can easily scale to handle increasing amounts of data and more complex processes without requiring significant reprogramming.
  • Adaptability: ML allows BPA systems to adapt to changing business conditions, making them more flexible and responsive to dynamic environments.

3.2 Artificial Intelligence and Machine Learning

  • Explain key differences between AI and ML.

  Content

 

Artificial Intelligence (AI) vs Machine Learning (ML)

Artificial Intelligence (AI) refers to the development of computer systems that can perform tasks typically requiring human intelligence. These tasks include reasoning, problem-solving, understanding natural language, perception (e.g., visual processing), and decision-making. AI aims to simulate or replicate aspects of human cognition and behaviour.

AI can be classified into two main types:

  1. Narrow AI (Weak AI): This is the most common form of AI, designed to perform a specific task, such as speech recognition (e.g., Siri or Google Assistant) or image classification.
  2. General AI (Strong AI): This is a theoretical form of AI that would have the ability to perform any intellectual task that a human can do. Currently, no such system exists.

 

While, Machine Learning (ML) is a subset of AI that focuses on the idea that systems can learn from data, identify patterns, and make decisions with minimal human intervention. Instead of being explicitly programmed to carry out every task, ML algorithms are designed to "learn" from vast amounts of data and improve their performance over time.

 

Think of Artificial Intelligence (AI) as the big idea—like trying to build machines that can act and think like humans. AI covers everything from making decisions, understanding languages, recognising objects, and even playing games.

Now, Machine Learning (ML) is a specific method within AI. It's like teaching a machine by showing it lots of examples so that it can learn on its own. Instead of telling it exactly what to do for every situation, we give it data, and it figures out the best way to make decisions.

The key differences are:

  • AI is the big picture, aiming to create smart systems. ML is just one way to do that, focusing on learning from data.

  • AI can follow pre-set rules (like a robot that follows instructions). But ML is all about learning from data to get better without being given specific instructions for every task.

  • AI can do many things, like controlling robots or translating languages. ML focuses more on tasks like finding patterns in data or predicting outcomes (like recommending shows on Netflix).

 

Artificial Intelligence Examples

  1. AI in Virtual Assistants
    Virtual assistants like Siri, Google Assistant, and Alexa use AI to process and respond to voice commands, answer questions, and manage tasks like setting alarms or sending texts. AI enables these systems to understand natural language and simulate human-like conversations.

  2. AI in Healthcare
    AI is transforming healthcare by supporting doctors in diagnosing diseases. It can analyse medical images, detect anomalies (such as tumours or fractures), and even predict the likelihood of patient outcomes based on previous medical data. AI systems assist with decision-making in treatments and surgeries.

  3. AI in Video Games
    In video games, AI is used to create intelligent NPCs (Non-Playable Characters) that can respond to the player’s actions. These characters learn from player behaviour and adapt to offer challenges or simulate real-life interactions, making the gaming experience more immersive.

  4. AI in Smart Home Devices
    Devices like smart thermostats (e.g., Nest) and smart lighting systems use AI to learn your habits and preferences, automatically adjusting the temperature or lighting based on your routine. Over time, these systems predict your preferences, improving energy efficiency and convenience.

  5. AI in Fraud Detection
    Financial institutions use AI to detect fraudulent activities. AI systems monitor transactions and identify unusual patterns that may indicate fraud, such as unusual spending behaviour or location changes, helping to prevent unauthorised transactions.

Machine Learning Examples

  1. ML in Recommendations
    Streaming platforms like Netflix and Spotify use machine learning to recommend movies, shows, or music based on a user's previous choices. The more you watch or listen, the better the system becomes at suggesting content tailored to your tastes.

  2. ML in Self-Driving Cars
    Self-driving cars like those from Tesla use ML to interpret data from cameras, sensors, and GPS systems to navigate roads. The car learns to recognise obstacles, traffic signs, and other vehicles, improving its driving abilities with each trip and data input.

  3. ML in Email Spam Filters
    Gmail and other email providers use ML to classify emails as spam or legitimate. The system learns from millions of emails to detect patterns in spam messages, such as specific words or senders, and becomes more effective over time at keeping your inbox clean.

  4. ML in Social Media Feeds
    Platforms like Instagram, Facebook, and Twitter use ML algorithms to personalise your news feed. The system analyses your interactions, such as likes, shares, and comments, and curates content that it predicts will interest you most, keeping your feed relevant.

  5. ML in Predictive Text
    Smart keyboards and applications like Google’s predictive text use machine learning to predict what word you might want to type next. By analysing your typing history and common phrases, these systems suggest words or auto-complete sentences to make typing faster and more accurate.

  6. ML in Online Shopping
    E-commerce sites like Amazon use ML to recommend products based on your previous purchases, browsing history, and what similar customers have bought. ML helps personalise the shopping experience by predicting what you might want to buy next.

  7. ML in Voice Recognition
    Voice assistants and speech-to-text systems, such as Google’s Voice Typing or Apple’s Dictation, use ML to continually improve their ability to recognise different accents, speech patterns, and languages. This allows the system to better understand users' spoken commands over time.

  Content

Machine learning models are designed to enable computers to learn and make decisions or predictions based on data. The way these models are trained determines their capabilities and applications. There are several key models of training, each suited to different types of tasks and datasets.

In this page, we explore the main models of training in machine learning: supervised learning, unsupervised learning, semi-supervised learning, and reinforcement learning. Each model uses distinct techniques for processing data, from learning with labelled examples to discovering patterns autonomously or improving through trial and error. Understanding these models is fundamental to applying machine learning effectively across various real-world problems.

 

Supervised Learning

Supervised learning is the most common type of machine learning model. In this approach, the model is trained on a labelled dataset, meaning that each input has a corresponding output (also known as the target or label). The algorithm learns to map inputs to the correct outputs, so when it encounters new, unseen data, it can make accurate predictions based on the learned relationships.

Key Characteristics:

  • Labelled Data: Each training example includes both an input and its correct output.
  • Task: The model learns to generalise from the input-output pairs to make predictions on unseen data.
  • Example Algorithms: Linear Regression, Decision Trees, Support Vector Machines (SVM), Neural Networks.

Example Application:

  • Spam Detection: The model is trained on a dataset of emails, where each email is labelled as "spam" or "not spam." Once trained, the model can predict whether a new email is spam.

Unsupervised Learning

Unsupervised learning operates without labelled data. Instead, the model is given unlabelled data and tasked with finding hidden patterns or structures within that data. The primary goal is to identify groupings or similarities between data points, often used for tasks like clustering or dimensionality reduction.

Key Characteristics:

  • No Labels: Data is not labelled, and the model must infer patterns based on the input data alone.
  • Task: The model looks for similarities or structures in data, such as grouping data points into clusters.
  • Example Algorithms: K-Means Clustering, Hierarchical Clustering, Principal Component Analysis (PCA).

Example Application:

  • Customer Segmentation: In marketing, unsupervised learning can be used to group customers based on their buying behaviour, enabling businesses to target specific segments with personalised offers.

Semi-Supervised Learning

Semi-supervised learning is a hybrid approach that combines elements of both supervised and unsupervised learning. This model is trained on a small amount of labelled data and a large amount of unlabelled data. The idea is that the labelled data can help guide the learning process while leveraging the abundance of unlabelled data to improve performance.

Key Characteristics:

  • Limited Labelled Data: Only a portion of the data is labelled.
  • Task: The model uses the labelled data to guide the learning process, improving performance by incorporating unlabelled data.
  • Example Algorithms: Self-training, Label Propagation, Semi-supervised Support Vector Machines (S3VM).

Example Application:

  • Image Recognition: Labelling large datasets of images can be time-consuming and expensive. Semi-supervised learning allows for the use of fewer labelled images while still achieving high accuracy in classifying new images.

Reinforcement Learning

Reinforcement learning involves training a model through interactions with an environment. The model, often called an agent, learns by receiving feedback in the form of rewards or penalties based on the actions it takes. The goal is to learn a strategy, or policy, that maximises the cumulative reward over time.

Key Characteristics:

  • Trial and Error: The agent explores different actions to discover which ones yield the best rewards.
  • Task: The model learns to make decisions by balancing exploration (trying new actions) and exploitation (using known actions that yield high rewards).
  • Example Algorithms: Q-Learning, Deep Q-Networks (DQN), Proximal Policy Optimisation (PPO).

Example Application:

  • Game Playing: In video games like chess or Go, reinforcement learning models can be trained to play by rewarding the model for making moves that lead to a win. Notable examples include AlphaGo and AlphaZero.

Learning Intention - Students will:

Success Criteria - Students can:

  • Identify key machine learning algorithms commonly used in data analysis, virtual assistants, and image recognition.
  • Explain how these algorithms are applied in real-world scenarios.

  Content

Machine learning (ML) algorithms are at the core of many modern technologies, driving innovation across industries. These algorithms enable machines to learn from data, recognise patterns, and make decisions with minimal human intervention. Understanding their applications is essential for harnessing their potential to solve complex problems.

In this page, we explore three key areas where ML algorithms are widely applied: data analysis and forecasting, virtual personal assistants, and image recognition. These applications illustrate the versatility and impact of machine learning in automating tasks, improving accuracy, and enhancing user experiences in everyday life.

 

Data Analysis and Forecasting

Machine learning is widely used for analysing large datasets and making predictions. Common ML algorithms for this include linear regression, decision trees, and neural networks.

  • Data Analysis: ML algorithms can identify patterns and correlations in large datasets that are beyond human capacity to analyse. For example, clustering algorithms like k-means group data points based on similarity, allowing businesses to segment customer groups based on purchasing behaviour or preferences.

  • Forecasting: Predictive models, such as time series algorithms and regression models, are used to make forecasts based on historical data. In financial markets, ML models analyse past stock performance to predict future trends. In weather forecasting, recurrent neural networks (RNNs) are employed to model temporal data and predict future weather conditions based on past data patterns.

 

Netflix's Content Recommendations

  • Algorithm Used: Collaborative Filtering (Matrix Factorisation)
  • Application: Netflix uses collaborative filtering algorithms to analyse user preferences and viewing history to predict what content viewers are likely to enjoy. By analysing vast amounts of user data (watch time, ratings, searches), Netflix can forecast what a user might want to watch next, leading to highly personalised recommendations. This data-driven forecasting helps Netflix retain subscribers by keeping them engaged with tailored content.

Read more about this example here.

 

 

Virtual Personal Assistants

Virtual personal assistants like Siri, Alexa, and Google Assistant rely heavily on machine learning algorithms to understand and respond to user requests.

  • Natural Language Processing (NLP): ML algorithms like recurrent neural networks (RNNs) and transformers (e.g., BERT and GPT models) enable virtual assistants to process, understand, and generate human language. These models can interpret voice commands, answer questions, and even perform tasks like setting reminders.

  • Speech Recognition: Algorithms such as Hidden Markov Models (HMMs) and deep learning networks convert spoken language into text that can be understood by the system. Virtual assistants use these models to transcribe speech and process it as input.

  • Personalisation and Recommendations: Through reinforcement learning and collaborative filtering, virtual assistants can learn user preferences over time and tailor responses and recommendations. For example, they might suggest apps or music based on past interactions or usage patterns.

 

Amazon Alexa

  • Algorithm Used: Deep Neural Networks (DNNs) for Speech Recognition and Natural Language Processing (NLP)
  • Application: Amazon Alexa is one of the most popular virtual personal assistants. Alexa uses deep learning algorithms to convert speech into text, understand user queries, and provide responses or execute tasks. For instance, when a user says, “Turn off the living room lights,” Alexa processes the voice command using natural language processing and interacts with connected smart devices to perform the requested action.

Learn more about Amaxon Alexa's architecture here.

 

Image Recognition

 Image recognition is one of the most prominent applications of machine learning, particularly in fields like healthcare, security, and social media.

  • Convolutional Neural Networks (CNNs): These are the cornerstone of most image recognition systems. CNNs are used to identify patterns within images, making them effective for tasks like facial recognition, medical image analysis (e.g., detecting tumors in X-rays), and autonomous vehicle navigation.

  • Object Detection and Classification: Algorithms such as YOLO (You Only Look Once) and RCNN (Region-based CNN) are used to detect and classify objects within images. These are applied in areas like surveillance, where detecting suspicious items or identifying individuals is crucial, and in social media, where photos are automatically tagged based on face recognition.

  • Medical Imaging: In healthcare, image recognition algorithms are trained to detect abnormalities in radiology images, such as tumours, fractures, or lesions. Deep learning models such as CNNs are particularly effective in analysing MRI or CT scans.

 

Tesla's Autopilot

  • Algorithm Used: Convolutional Neural Networks (CNNs)
  • Application: Tesla’s Autopilot uses CNNs to analyse images from multiple cameras mounted on the car to detect and classify objects such as pedestrians, road signs, and other vehicles. These models allow the car to "see" its surroundings and make driving decisions such as lane keeping, adaptive cruise control, and automatic parking. CNNs enable Tesla's Autopilot to process the visual data in real time, contributing to the development of autonomous driving technologies.

3.5 Models for Designing and Analysing

Syllabus

Research models used by software engineers to design and analyse ML including:

  • decision trees
  • neural networks

  Learning Intention and Success Criteria

Learning Intention - Students will:

  • Understand and describe the models used by software engineers to design and analyse machine learning systems, focusing on decision trees and neural networks.

Success Criteria - Students can:

  • Define and explain decision trees, including their structure, strengths, and limitations.
  • Describe neural networks, outlining their architecture, types, and applications.
  • Compare and contrast the benefits and drawbacks of decision trees and neural networks.

  Content

Machine learning (ML) models are integral to the development of intelligent systems, and software engineers rely on various models to design and analyse them. Two of the most commonly used models are decision trees and neural networks, each serving different purposes in the ML lifecycle. These models help software engineers understand data patterns, make predictions, and improve system performance.

 

Decision Trees

A decision tree is a visual diagram that represents all possible combinations of decisions and their resulting actions. It is commonly used in both classification and regression tasks in machine learning (ML). The structure of the tree follows a sequence of decisions, where each decision path leads to either another decision or a final action (or outcome).

The decision tree builds paths based on the conditions at each decision point. For example, if the current condition satisfies a decision criterion, the branch will move in one direction (e.g., "Yes"). If not, it will move in another (e.g., "No"). Each path eventually leads to either another decision or an end result, making it clear how a combination of conditions leads to specific outcomes.

Key Strengths

  • Interpretability: The flowchart-like structure makes decision trees easy to understand and interpret, showing how decisions lead to specific actions.

  • Versatility: Decision trees are useful for a wide range of problems, particularly when the goal is to map out possible outcomes based on a set of conditions.

Limitations

  • Overfitting: Decision trees can grow too complex when trained on noisy data, leading to overfitting.

  • Instability: Small changes in the data can lead to a very different tree structure.

Common Use Cases

  • Classification: E.g., determining whether an email is spam or not.

  • Regression: E.g., predicting the price of a house based on its features like size and location.

 

Neural Networks

Neural networks (NNs) are a foundational model in machine learning, particularly when dealing with large and complex datasets. They are inspired by the biological neural networks in the human brain and are capable of learning patterns, making predictions, and transforming raw data into actionable insights.

 

 

Neural networks are at the core of deep learning, a subset of machine learning that has advanced fields such as computer vision, natural language processing (NLP), and reinforcement learning. The power of neural networks lies in their ability to capture highly non-linear relationships, making them suitable for both structured (e.g., tabular) and unstructured (e.g., images, text) data.

 

Structure

A neural network is composed of three main types of layers:

  1. Input Layer
    • This layer takes in the raw data as input. Each node in the input layer represents one feature of the data (e.g., pixel values in an image, numerical features in tabular data, or words in a text).
  2. Hidden Layers
    • These are the layers between the input and output layers. A neural network can have multiple hidden layers, and each layer consists of neurons (nodes) that perform mathematical transformations on the input data. The more hidden layers, the "deeper" the network.
    • Activation Functions: Each neuron applies an activation function to introduce non-linearity into the model, allowing it to learn complex patterns. Common activation functions include:
      • ReLU (Rectified Linear Unit): Sets negative values to zero and leaves positive values unchanged, making it highly efficient for deep learning models.
      • Sigmoid: Maps values between 0 and 1, often used in binary classification tasks.
      • Tanh (Hyperbolic Tangent): Maps values between -1 and 1, allowing negative values to have a stronger influence on the output than Sigmoid.
  3. Output Layer
    • The output layer produces the final prediction based on the learned weights and transformations. For example:
      • In classification tasks, the output might be a probability distribution over different classes (e.g., "cat" or "dog" in image classification).
      • In regression tasks, the output is typically a continuous value (e.g., predicting a house price).

 

 

Learning Mechanism

The learning process in neural networks involves the following steps:

  1. Forward Propagation: Data moves from the input layer, through the hidden layers, to the output layer. Each neuron applies a weighted sum of its inputs, passes the result through an activation function, and forwards the output to the next layer.

  2. Loss Function: The loss function calculates the error between the predicted output and the actual target. For instance:

    • Mean Squared Error (MSE) is commonly used in regression tasks.
    • Cross-Entropy Loss is used for classification tasks, measuring how far the predicted probability distribution is from the actual distribution.

  3. Backpropagation: Once the loss is calculated, the model adjusts the weights of the connections using an optimisation algorithm, typically gradient descent. Gradient descent updates the weights in the direction that minimises the error, with the learning rate controlling the size of the steps taken during each update.

  4. Training and Convergence: The process of forward propagation, loss computation, and backpropagation is repeated iteratively over many epochs (iterations of the training dataset). The network learns to minimise the loss, improving its performance.

Types of Neural Networks

Different types of neural networks are optimised for specific tasks. Below are the most prominent types:

1. Feedforward Neural Networks (FNN)

  • Structure: Data moves in one direction, from input to output, without cycles or feedback loops.

  • Use Cases: Simple tasks such as regression or basic classification (e.g., predicting the outcome of a stock market price).

 

2. Convolutional Neural Networks (CNN)

  • Structure: CNNs have a specialised architecture for handling grid-like data such as images. They consist of convolutional layers that apply filters (kernels) to detect local patterns such as edges, textures, or colours. After convolution, pooling layers reduce the spatial dimensions, preserving essential information while reducing computational cost.

  • Use Cases: Computer vision tasks like image classification (e.g., identifying objects in images), object detection (e.g., detecting faces in a picture), and video analysis.

 

 

3. Recurrent Neural Networks (RNN)

  • Structure: RNNs are designed for sequence data (e.g., time series, text, or speech). They have feedback connections that allow information to be passed from one time step to the next. This structure makes them powerful for capturing temporal dependencies in data.

  • Variants: Long Short-Term Memory (LSTM) networks and Gated Recurrent Units (GRU) are special types of RNNs designed to overcome the problem of vanishing gradients, allowing the network to remember long-term dependencies.

  • Use Cases: Time series forecasting, language translation, speech recognition.

 

4. Deep Neural Networks (DNN)

  • Structure: These are neural networks with multiple hidden layers. The depth allows the network to learn more abstract and complex features from the data. However, training these networks requires large datasets and computational power.

  • Use Cases: Deep learning applications such as recommendation systems (e.g., Netflix movie recommendations), autonomous vehicles, and advanced AI systems like OpenAI's GPT.

 

5. Generative Adversarial Networks (GANs)

  • Structure: GANs consist of two networks, a generator and a discriminator, that are trained together. The generator creates fake data, and the discriminator evaluates whether the data is real or fake. This adversarial process continues until the generator produces realistic outputs.

  • Use Cases: Image generation (e.g., generating realistic faces), style transfer, and deepfake creation.

 

Check out this fascinating challenge: Which Face Is Real? Can you tell the difference between a real human face and one generated by artificial intelligence (AI)?

The faces in this challenge are generated by a Generative Adversarial Network (GAN), where two neural networks—the generator and the discriminator—compete in a process known as adversarial training. The generator creates increasingly realistic fake faces, while the discriminator tries to distinguish them from real faces. Over time, the generator improves to the point where even humans find it difficult to tell which face is real and which is AI-generated.

Key Concepts

  1. Weight Initialisation

    • The initial values of the weights can significantly impact how fast the network converges. Poor initialisation may lead to vanishing gradients or slow training. Common strategies include Xavier initialisation or He initialisation.

  2. Regularisation

    • To prevent overfitting, various techniques are applied:
      • Dropout: Randomly drops a subset of neurons during training, forcing the network to learn more robust features.
      • L2 Regularisation (Weight Decay): Penalises large weights by adding a term to the loss function, helping to generalise better.

  3. Batch Normalisation

    • Batch normalisation normalises the input to each layer, ensuring that the inputs are on a similar scale. This technique speeds up training and improves performance by reducing internal covariate shift.

  4. Optimisation Algorithms

    • Gradient Descent Variants: Standard gradient descent can be computationally expensive. Variants like Stochastic Gradient Descent (SGD), Adam (Adaptive Moment Estimation), and RMSprop adapt the learning rate during training, accelerating convergence.

Strengths & Limitations

Strengths of Neural Networks

  • Versatility: Can be applied to various tasks, from image recognition to language processing.

  • Representation Learning: Automatically learns features from raw data, reducing the need for manual feature engineering.

  • Scalability: Can handle massive datasets and is capable of scaling across distributed systems (e.g., cloud computing frameworks like TensorFlow or PyTorch).

  • State-of-the-Art Performance: Especially in tasks such as speech recognition, object detection, and game playing.

 

Limitations of Neural Networks

  • Data Hungry: Neural networks typically require large datasets for optimal performance. Small datasets may lead to overfitting and poor generalisation.

  • Computationally Intensive: Training deep neural networks is resource-heavy, requiring high-performance hardware such as GPUs or TPUs.

  • Black Box Nature: Despite their success, neural networks are often criticised for their lack of interpretability. It can be difficult to understand why a network makes certain decisions.

  • Overfitting: Without proper regularisation, neural networks may perform very well on training data but fail to generalise to new, unseen data.

3.6 Types of Machine Learning Algorithms

Syllabus

Describe types of algorithms associated with ML, including:

  • linear regression
  • logistic regression
  • K-nearest neighbour

  Learning Intention and Success Criteria

Learning Intention - Students will:

  • Understand different types of machine learning algorithms and their purposes, with a focus on linear regression, logistic regression, and K-nearest neighbour.

Success Criteria - Students can:

  • Explain the function and purpose of linear regression in machine learning.
  • Describe logistic regression and its application in classification tasks.
  • Identify how the K-nearest neighbour algorithm works and when it is used.

  Content

In machine learning, algorithms are the foundation for making predictions and uncovering patterns in data. Different types of algorithms are designed for various tasks, such as predicting continuous values or classifying data into categories. This page will explore three fundamental algorithms:

  • Linear regression, which predicts continuous outcomes by modelling relationships between variables.
  • Logistic regression, which classifies data into distinct categories based on probability.
  • K-nearest neighbour (KNN), which makes predictions by comparing new data points to similar instances in the dataset.

Understanding how these algorithms work and when to apply them is crucial for solving diverse problems in data analysis and prediction.

 

What is Regression?

Regression is a type of machine learning algorithm used to predict continuous values. It helps to understand the relationship between one or more input variables (also called features or independent variables) and an output variable (the dependent variable).

In simple terms, regression tries to find a pattern in data and uses that pattern to make predictions. For example, it can help predict things like:

  • A house's price based on its size and location.
  • A student's test score based on the number of hours they studied.

In regression, the goal is to find the best line or curve that fits the data points, allowing us to predict future outcomes accurately.

 

Linear Regression

Linear regression is a type of algorithm that helps predict continuous values, meaning numbers that can go up or down like prices, scores, or temperatures. It tries to find a straight line that best fits the data and shows the relationship between a set of inputs (called independent variables) and the result (the dependent variable).

How It Works:

Imagine you want to predict someone's exam score based on the number of hours they studied. Linear regression will draw a line on a graph of the data (like hours studied on one axis and scores on the other). This line helps us make predictions, like "If you study for 4 hours, your predicted score is 85."

Predicted Score=Line equation=β0+β1×(hours studied)

Where β0\beta_0​ is the starting point (where the line crosses the Y-axis), and β1\beta_1​ shows how much the score increases for each extra hour studied.

Example:

If you want to predict the price of a house based on its size (in square meters), linear regression helps create a formula. The bigger the house, the higher the price, and linear regression shows this as a line on a graph.

 

 

Logistic Regression

Logistic regression is used for classification tasks, which means putting things into categories. It's great when you need to decide between two or more options, like "yes" or "no," "pass" or "fail," or "spam" and "not spam."

How It Works:

Instead of predicting a number like linear regression, logistic regression predicts the probability of something happening. For example, if you were predicting whether a student passes or fails based on their study hours, logistic regression gives you a probability, like "There’s a 90% chance this student will pass."

The algorithm uses something called a sigmoid function to turn any number into a probability between 0 and 1. If the probability is greater than 0.5, it might say "yes" (pass), and if it’s lower, it might say "no" (fail).

Example:

A school might use logistic regression to predict whether students will pass an exam based on their homework scores and study hours. It will classify each student into either "pass" or "fail" by calculating the likelihood for each category.

 

 

K-Nearest Neighbour (KNN)

K-nearest neighbour, or KNN, is an algorithm used for both classification and regression. It’s very simple—it predicts new outcomes by looking at the results of the K most similar examples (or neighbours) in the data.

How It Works:

Imagine you want to classify whether a fruit is an apple or an orange based on its size and colour. KNN works by comparing a new fruit to the closest examples in your dataset (like looking at its nearest neighbours). If most of the similar fruits are apples, it will classify the new fruit as an apple. You decide how many neighbours to compare by choosing a value for K.

Steps:

  1. Pick a number K which is the number of neighbours to look at.
  2. For a new data point, check the K closest data points in the training set (which is the data we already know).
  3. Majority vote: For classification, KNN assigns the class that most of these neighbours belong to (like deciding if the new fruit is an apple or orange). For regression, it takes the average of these neighbours' values.

Example:

If you want to predict what kind of animal a new image shows, KNN will look at other images nearby in the data. If most of the nearest images show dogs, it will classify the new image as a dog too.
