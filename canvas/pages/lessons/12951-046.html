2.6 World Wide Web Consortium

Syllabus

Investigate and explain the role of the World Wide Web Consortium (W3C) in the development of applications for the web, including:

  • Web Accessibility Initiative (WAI)
  • internationalisation
  • web security
  • privacy
  • machine-readable data

  Learning Intention and Success Criteria

Learning Intention - Students will:

  • Investigate and explain the role of the World Wide Web Consortium (W3C) in setting standards for web development, including initiatives related to web accessibility, internationalisation, web security, privacy, and machine-readable data.

Success Criteria - Students can:

  • Describe the purpose and impact of the Web Accessibility Initiative (WAI) in making web content accessible to people with disabilities.
  • Explain how W3C standards support internationalisation, allowing web applications to be used by a global audience in multiple languages and cultures.
  • Identify W3C guidelines that enhance web security and protect user privacy in web applications.
  • Understand the importance of W3C standards for machine-readable data, such as RDF and Linked Data, in enabling the semantic web and data interoperability.

  Content

The World Wide Web Consortium (W3C) is the main international standards organisation for the web, founded by Tim Berners-Lee in 1994. It develops open standards to ensure the long-term growth of the Web. Below are key initiatives and areas where the W3C has a significant impact on web development.

 

Web Accessibility Initiative (WAI)

The Web Accessibility Initiative (WAI) is a core program of the W3C that develops strategies, guidelines, and resources to make the web accessible to people with disabilities.

  • Accessible Rich Internet Applications (WAI-ARIA): WAI-ARIA is a set of specifications that provide ways to make web applications accessible, especially dynamic content and advanced user interface controls.
  • Authoring Tool Accessibility Guidelines (ATAG) and User Agent Accessibility Guidelines (UAAG): These guidelines focus on ensuring that tools used to create and consume web content are accessible. ATAG addresses accessibility in content creation tools, while UAAG focuses on browsers and media players.
  • Web Content Accessibility Guidelines (WCAG): WCAG provides a framework for making web content more accessible. It is structured around four principles: Perceivable, Operable, Understandable, and Robust (POUR). The guidelines are divided into three levels of conformance: A, AA, and AAA, with AAA being the highest standard.

 

Internationalisation

W3C’s internationalisation activities ensure that web applications and content can be used by people around the world, regardless of language, region, or cultural background.

  • Character Encoding and Text Direction: Standards such as UTF-8 and guidelines on bidirectional (BiDi) text support ensure that web content is correctly displayed in multiple languages, including those with complex scripts and right-to-left writing directions.
  • Language and Locale Identification: The use of attributes like lang in HTML and standards such as BCP 47 for language tags enable accurate language identification and proper rendering of localised content.
  • Cultural Adaptation: W3C provides best practices for handling region-specific date formats, currency, numbering systems, and other cultural nuances. This is crucial for creating user-friendly, localised web applications.

Web Security

Web security is a critical area where W3C standards aim to protect both users and web applications from various threats.

  •  Content Security Policy (CSP): CSP helps prevent cross-site scripting (XSS) attacks by allowing developers to specify which sources of content are trusted and can be safely loaded by the browser.
  • Secure Contexts: Many W3C APIs, such as Geolocation and WebRTC, require a secure context (HTTPS) to function, ensuring that sensitive data is transmitted securely.
  • WebAuthn: This standard provides a secure way to authenticate users through the browser, leveraging public-key cryptography instead of passwords. It is part of the FIDO2 project and aims to enhance security by reducing reliance on traditional passwords.

 

Privacy

W3C’s privacy standards aim to provide users with greater control over their personal information and ensure that web applications handle data responsibly.

  • Do Not Track (DNT): This was a proposal to enable users to express their preference not to be tracked across websites. While it is not widely adopted, it represents an important early effort in giving users control over their privacy.
  • Tracking Protection and Privacy Interest Group (PING): These groups focus on developing standards and best practices to minimise privacy risks and enhance transparency in data handling.
  • Privacy Sandbox: Recent initiatives are focused on developing a more privacy-friendly web environment, particularly in the context of advertising and tracking.

 

Machine-Readable Data

W3C promotes the use of structured, machine-readable data to enhance the interoperability and functionality of web applications.

  • Resource Description Framework (RDF): RDF is a framework for representing information about resources in the web. It is used in the Semantic Web to link related data.
  • Web Ontology Language (OWL): OWL builds on RDF and provides a richer vocabulary for describing properties and classes, enabling more complex relationships and reasoning about data.
  • SPARQL Protocol and RDF Query Language (SPARQL): SPARQL is used to query and manipulate RDF data. It allows for complex queries across diverse data sources.
  • JSON-LD (JavaScript Object Notation for Linked Data): JSON-LD is a lightweight format for structuring linked data using JSON, making it easier to integrate with existing web technologies and enabling more powerful data interoperability.

 

W3C Link Checker

The World Wide Web Consortium provides a series of tools to help maintain high-quality web standards. One of these is the W3C Link Checker, which scans your web pages for broken or outdated links. Try it out on some websites, see if you can find broken links.
