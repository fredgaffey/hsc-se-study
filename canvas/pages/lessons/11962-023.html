  Content

When variables are declared, they are assigned a specific Data Type which tell the computer how much memory is required to store a value.

The most common Data Types used in programming are:

  • Integer (Int)

  • Floating Point (Float)

  • Character (Char)

  • String (Str)

  • Boolean (Bool)

Variables can only store values that are of its own Data Type unless converted using Type Casting.

Depending on the Data Type being converted, there may be a loss of data (i.e. Type Casting from a Floating Point to Integer will lose the fraction component).

 

Integers

Like in Mathematics, Integers are whole numbers with no fractions or decimals. They are commonly stored as 4 bytes (32 bits) which allow for the accurate representation of all whole numbers between -2,147,483,648 to 2,147,483,647.

-27, -5, 0, 4, 15, 207

Note: The value of the integer itself does not affect the amount of memory used to store it (i.e. the integers -5, 1 and 500,000 are all 4 bytes in size).

Floating Point Numbers

Floating Point Numbers can represent decimal point values and can thus represent real numbers (not just whole numbers but also fractions). They are commonly stored as 4 bytes (32 bits) which allow for the approximate representation of decimal values.

-15.67, -6.5, 0, 7.08, 72.57

Note: The value of the floating point number itself does not affect the amount of memory used to store it (i.e. the integers -5.8, 0 and 708.91 are all 4 bytes in size).

Floating Point Numbers are only approximate representations of a given number, so it will pose a risk to applications that require a great deal of accuracy. Thus, there are other data types that use more memory to store more accurate representations of numbers such as Double which uses 8 bytes instead of 4.

Characters

Characters are single letters and symbols that are defined and encoded within the ASCII table by being assigned a unique numerical value. They are commonly stored as 1 byte (8 bits) per character and thus limits the range of letters and symbols that can be represented using this data type.

'a', 'b', 'c', 'A', 'B', 'C', '$', '@', '%', ' ', '\n', '\t'

Note: '\n' means to create a new line of text and '\t' means to print a tab space

The most popular character encoding method on the web is UTF-8 as it allows for the representation of other languages and emojis.

   Note that Python does not have a specific data type for characters. Instead, they are simply represented as strings with a length of one.

Strings

Strings are an array of characters. Since each character is stored as 1 byte each, a string's size depends on the number of characters in the string.

# These two strings are the same 
string_1 = "Hello World"
string_2 = ['H', 'e', 'l', 'l', 'o', ' ', 'W', 'o', 'r', 'l', 'd']

Hence, we can interact with a string like an array (see 1.15 for more information about arrays).

string = "Hello World"

# Output: 'o'
print(string[4])

Combining multiple strings together is called Concatenation.

string_1 = "Hello" 
string_2 = "World" 
full_string = string_1 + ' ' + string_2

# Output: "Hello World"
print(full_string)

Note: ' ' is a space character

Boolean

Booleans are a two-state data type because they only have two possible values, either TRUE or FALSE. They are mainly associated with conditional statements (in loops, if statements, etc) that change the flow of logic in a program. They are commonly stored as 1 bit and thus limits the data type as either a literal 1 or 0.

flag = false 

IF flag = true THEN
    Display "Flag is set to TRUE" 
ELSE 
    Display "Flag is set to FALSE" 
ENDIF

In the example above, the program would print "Flag is set to FALSE" because if the boolean is not TRUE, then it must be FALSE.

Date and Time

Date and time is not a standard data type in Python, however we can use a module called datetime to work with dates and times. Here's an example of getting the current date and time.

import datetime

current_time = datetime.datetime.now()

# Output: 2024-02-23 16:16:05.864977
print(current_time)

We can also specify our own date and time.

import datetime

birthday = datetime.datetime(2024, 8, 3)

# Output: 2024-02-23 16:16:05.864977
print(birthday)

Note: The datetime function requires at least 3 parameters (year, month, day). The function can also take in further optional parameters (year, month, day, hour, minute, second, microsecond, timezone). Any optional parameters that are left out are set to a default value of 0.
